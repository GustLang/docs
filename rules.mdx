Gust reports findings with stable codes. `F###` codes are formatter passes applied by `gust format`, `G####` codes are analyzer errors, and `W####` codes are analyzer warnings. A code marked in the **Fix** column is auto-repaired — `gust format` for `F` codes, `gust check --fix` for fixable `W` codes. Run `gust explain <code>` for the long-form text of any `G` / `W` code.

These tables list every code at a glance; follow a section in the sidebar for the full description of each rule. Generated from the rule registry and the formatter pass list — see `gustc/rules/` and `gustc/formatter/`.
