Dynamic array (slice). Backed by `GSlice*` in the C runtime.

Literals:

```gust
["a", "b", "c"]     # list of strings
[1, 2, 3]           # list of integers
[]                  # empty list (type inferred from context)
```

Operators:

```gust
in, not in          # containment check: 3 in [1, 2, 3] → true
for x in xs         # iterate elements
for a, b in pairs   # tuple unpack — element type must be tuple[A, B]
```

Access:

```gust
items[0]            # index access (0-based)
items[i]            # variable index
items[a:b]          # slice — returns a new list[T]
```

## Fields

- `length: integer` — Number of elements currently in the list.

## Methods

<a id="list.append" />
```gust
def list.append(item: T) -> none
```

Add an element to the end of the list.

**Parameters**

- `item: T` — The element to append.

---

<a id="list.insert" />
```gust
def list.insert(index: integer, item: T) -> none
```

Insert `item` at `index`, shifting subsequent elements right. An
out-of-range index is clamped to [0, length].

**Parameters**

- `index: integer` — Position to insert at, clamped to [0, length].
- `item: T` — The element to insert.

---

<a id="list.pop" />
```gust
def list.pop() -> T
```

Remove and return the last element.

**Raises**

- `IndexError` — When the list is empty.

---

<a id="list.pop_at" />
```gust
def list.pop_at(index: integer) -> T
```

Remove and return the element at `index`.

**Parameters**

- `index: integer` — Zero-based position of the element to remove.

**Raises**

- `IndexError` — When `index` is outside `0..length`.

---

<a id="list.extend" />
```gust
def list.extend(other: list[T]) -> none
```

Append every element of `other` to this list.

**Parameters**

- `other: list[T]` — The list whose elements are appended.

---

<a id="list.delete" />
```gust
def list.delete(index: integer) -> bool
```

Remove the element at the given index, shifting remaining elements.
Returns true if the index was in range, false otherwise (no-op).

**Parameters**

- `index: integer` — Zero-based position of the element to remove.

---

<a id="list.clear" />
```gust
def list.clear() -> none
```

Remove every element, leaving the list empty.

---

<a id="list.copy" />
```gust
def list.copy() -> list[T]
```

Return a shallow copy.

---

<a id="list.slice" />
```gust
def list.slice(start: integer, stop: integer) -> list[T]
```

Return a new list with elements from `start` (inclusive) to `stop`
(exclusive). Equivalent to `xs[start:stop]`.

**Parameters**

- `start: integer` — Inclusive start index of the slice.
- `stop: integer` — Exclusive end index of the slice.

---

<a id="list.index_of" />
```gust
def list.index_of(item: T) -> integer
```

Return the index of the first occurrence of `item`, or -1 if absent.
Works on list[string], list[integer], list[float].

**Parameters**

- `item: T` — The element to search for.

---

<a id="list.count" />
```gust
def list.count(item: T) -> integer
```

Return the number of times `item` appears in the list.
Works on list[string], list[integer], list[float].

**Parameters**

- `item: T` — The element to count occurrences of.

---

<a id="list.contains" />
```gust
def list.contains(item: T) -> bool
```

True if `item` appears anywhere in the list. The method form of `item in xs`.
Works on list[string], list[integer], list[float].

**Parameters**

- `item: T` — The element to test for membership.

---

<a id="list.sort" />
```gust
def list.sort() -> none
```

Sort the list in ascending order. Works on list[string], list[integer], list[float].

---

<a id="list.reverse" />
```gust
def list.reverse() -> none
```

Reverse the list in place.

---

<a id="list.join" />
```gust
def list.join(sep: string) -> string
```

Concatenate elements with `sep` between them. list[string] only.

**Parameters**

- `sep: string` — The separator inserted between elements.

**Examples**

```gust
["a", "b", "c"].join(", ") → "a, b, c"
```
