title: float
description: "64-bit double-precision floating point"
---

64-bit double-precision floating point. Backed by `double` in the C runtime.

Literals:

```gust
3.14                # decimal float
-0.5                # negative
1e10                # scientific notation
```

Operators:

```gust
+ - * /             # arithmetic — `/` raises ValueError on division by zero
== != < > <= >=     # comparison
# (// and % are integer-only — cast operands to integer first)
```

Casting:

```gust
"3.14" as float     # parse from string (raises ValueError on bad input)
42 as float         # widen from integer
x as string         # float to string
x as integer        # truncate toward zero
```

Display: whole numbers show as X.0, others use shortest representation
Range: see math.max_float() and math.min_float()
Special values: see math.inf(), math.nan(), math.is_nan(), math.is_inf()

when `x` is NaN.
