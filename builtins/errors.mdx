---
title: Errors
description: "The standard error types, available in every program without an import"
---

The standard error types are part of the prelude — available everywhere with no `use`.
```gust
raise ValueError(message: "...") # Raise the error
try
    ...
catch ValueError as e # Catch the error (as e is optional)
    ...
end
```

<a id="ValueError" />
```gust
def ValueError implements Error
    message: string
end
```

General-purpose error for invalid values or arguments.

---

<a id="IOError" />
```gust
def IOError implements Error
    message: string
    path: string
end
```

File or I/O operation failed.

---

<a id="IndexError" />
```gust
def IndexError implements Error
    message: string
    index: integer
end
```

Index out of bounds.

---

<a id="KeyError" />
```gust
def KeyError implements Error
    message: string
    key: string
end
```

Missing dictionary key.

---

<a id="RuntimeError" />
```gust
def RuntimeError implements Error
    message: string
end
```

A general runtime failure — an operation that cannot be completed, is
unsupported, or is not implemented.

---

```gust
def SegmentationViolationError implements Error
```

---

<a id="BusError" />
```gust
def BusError implements Error
    message: string
```

<a id="AbortError" />

```gust
def AbortError implements Error
    message: string
end
```

---

<a id="TerminatedError" />

```gust
    message: string
end
```

---

<a id="HangupError" />
```gust
def HangupError implements Error
    message: string
end
```

---

<a id="QuitError" />
```gust

    message: string
```

---

<a id="SignalError" />
