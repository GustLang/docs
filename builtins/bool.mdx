Boolean value. Backed by `bool` (`stdbool.h`) in the C runtime.

Literals:
```gust
  true
  false
```

Operators:
```gust
  and                 # logical AND
  or                  # logical OR
  not                 # logical NOT
  == !=               # equality
  is, is not          # identity check (mainly for none)
```

Casting:
```gust
  x as string         # "true" or "false"
  x as integer        # 1 if true, 0 if false
  x as float          # 1.0 if true, 0.0 if false
```

## Dunders

<a id="bool.__string" />
```gust
def bool.__string() -> string
```

Triggered by `print(b)` and f-string interpolation. Returns "true" or "false".

---

<a id="bool.__integer" />
```gust
def bool.__integer() -> integer
```

Triggered by `b as integer`. Returns 1 for `true`, 0 for `false`.

---

<a id="bool.__float" />
```gust
def bool.__float() -> float
```

Triggered by `b as float`. Returns 1.0 for `true`, 0.0 for `false`.

---

<a id="bool.__bool" />
```gust
def bool.__bool() -> bool
```

Triggered by `b as bool`. Identity conversion.
