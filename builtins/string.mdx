title: string
description: "Immutable sequence of characters"
---

Immutable sequence of characters. Backed by `char*` in the C runtime.

Literals:

```gust
"hello"             # string literal
f"value: {x}"       # f-string (interpolated)
triple-quoted form  # wrap text in three double-quotes for a multiline string
```

Operators:

```gust
+                   # concatenation: "a" + "b" → "ab"
==, !=              # equality comparison
< <= > >=           # lexicographic comparison
in, not in          # substring check: "el" in "hello" → true
```

Casting:

```gust
x as integer        # parse string as integer (raises ValueError on bad input)
x as float          # parse string as float (raises ValueError on bad input)
42 as string        # integer to string
3.14 as string      # float to string
```

## Fields

## Codecs

<a id="string.encode" />
```gust
def string.encode(format: string) -> string
```

Encode this string's bytes using the named scheme, returning text.
Supported formats:

```gust
* `"base64"` — RFC 4648 standard alphabet with `=` padding.
* `"hex"`    — lowercase hex, two chars per byte.
```

Length-aware: a string containing `0x00` is encoded in full, not truncated
at the first NUL.

**Parameters**

- `format: string` — The codec name, `"base64"` or `"hex"`.

**Raises**

- `ValueError` — When `format` is not `"base64"` or `"hex"`.

---

<a id="string.decode" />
```gust
def string.decode(format: string) -> bytes
```

Decode text previously produced by `.encode(format)` back to raw bytes.
Returns `bytes` (not a string) so a decoded payload containing `0x00` keeps
its true length. Same supported formats as `encode`.

**Parameters**

- `format: string` — The codec name, `"base64"` or `"hex"`.

**Raises**

- `ValueError` — When the input is malformed (bad length or an invalid character), or `format` is not `"base64"` or `"hex"`.
