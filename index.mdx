## Why Gust?

<CardGroup cols={2}>
  <Card title="Readable by design" icon="book-open">
    Python-style syntax with explicit `end` keywords. No braces, no semicolons, no significant-whitespace gotchas.
  </Card>
  <Card title="Native performance" icon="gauge">
    Source → C → native binary via your C toolchain. Benchmarks land within 2–3× of hand-written C.
  </Card>
  <Card title="Concurrent when you ask" icon="zap">
    Mark a `def!`, `for!`, or `while!` and the compiler spawns and joins threads for you. Plain code stays sequential.
  </Card>
  <Card title="Types without ceremony" icon="shapes">
    `name := "hi"` infers. `name: string = "hi"` annotates. Pick per line.
  </Card>
  <Card title="Honest error handling" icon="octagon-alert">
    Custom `error` types, `try` / `catch`, and stack messages with source context — not a wall of C traceback.
  </Card>
  <Card title="Batteries included" icon="battery-charging">
    A real standard library: `math`, `fs`, `os`, `json`, `regex`, `socket`, `http`, `websockets`, `cryptography`, `database`, and more.
  </Card>
  <Card title="A modern core" icon="cube">
    Closures and lambdas, enums that carry data with `match`, interfaces with default methods, `def Sub extends Parent` subclassing, unions and optionals, generics.
  </Card>
  <Card title="Tooling in the box" icon="wrench">
    Formatter, language server with a VS Code extension, REPL, `@test` runner, package manager, and a WebAssembly target — all in one `gust` binary.
  </Card>
</CardGroup>

## A taste

```gust
error LatencyError(message: string, server: string)

def Server
    name: string
    ip:   string
    online: bool
end

def Server.status() -> string
    return "online" if online else "offline"
end

def ping(name: string, ms: integer) -> string
    if ms > 500
        raise LatencyError(message: "too slow", server: name)
    end
    return name
end

def main() -> none
    servers: list[Server] = [
        Server(name: "s1", ip: "10.0.0.1", online: true),
        Server(name: "s2", ip: "10.0.0.2", online: false),
    ]

    for! s in servers
        try
            ok := ping(s.name, 120)
            print(f"{ok}: {s.status()}")
        catch LatencyError as err
            print(f"{err.server} slow: {err.message}")
        end
    end
end
```
