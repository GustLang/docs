```gust
use unsafe
```

Low-level manual memory access: allocation outside the managed heap, raw
loads and stores at a base address plus byte offset, block memory operations,
and sequentially-consistent atomics on an integer cell.

An `address` is an opaque machine word (spelled `integer`) that names a byte
in memory. It carries no element type, no length, and no lifetime — nothing
here is reference-counted or bounds-checked, and a bad address is undefined
behavior. This is the substrate for hand-written data structures that sit
beneath the managed collection types; ordinary code should use `list`, `dict`,
`bytes`, and `string` instead.

Allocations from `alloc`/`alloc_zeroed`/`resize` are owned by the caller and
must be released with `free` exactly once. They are invisible to the managed
heap: they are never scanned, never reference-counted, and never freed
automatically.

**Examples**

```gust
use unsafe

def main() -> none
    addr := unsafe.alloc(8)
    unsafe.store64(addr, 0, 42)
    print(unsafe.load64(addr, 0))   # 42
    unsafe.free(addr)
end
```

## Functions

<a id="unsafe.alloc" />
```gust
def foreign alloc(size: integer) -> integer
```

Allocate `size` bytes of uninitialized memory and return its address,
or `NULL_ADDRESS` if the request cannot be satisfied. Release it with
`free`.

**Parameters**

- `size: integer` — Number of bytes to allocate.

<Warning>
The block is invisible to the managed runtime — it is never
reference-counted or freed automatically. You must `free` it exactly
once and never use the address after freeing it. The bytes are
uninitialized; read them only after writing.
</Warning>

<a id="unsafe.alloc_zeroed" />
```gust
def foreign alloc_zeroed(count: integer, size: integer) -> integer
```

Allocate `count * size` bytes, zero-filled, and return the address, or
`NULL_ADDRESS` on failure. The product is computed with an overflow check.
Release it with `free`.

**Parameters**

- `count: integer` — Number of elements.
- `size: integer` — Byte size of one element.

<Warning>
The block is invisible to the managed runtime — it is never
reference-counted or freed automatically. You must `free` it exactly
once and never use the address after freeing it.
</Warning>

<a id="unsafe.resize" />
```gust
def foreign resize(addr: integer, size: integer) -> integer
```

Grow or shrink the block at `addr` to `size` bytes, preserving contents
up to the smaller of the old and new sizes, and return the (possibly
moved) address. Returns `NULL_ADDRESS` on failure, leaving the original
block intact. A `NULL_ADDRESS` input behaves like `alloc(size)`.

**Parameters**

- `addr: integer` — Address previously returned by an allocation function.
- `size: integer` — New size in bytes.

<Warning>
When the block moves, the original address is freed; using it after a
successful resize is undefined behavior. Use only the returned address.
</Warning>

<a id="unsafe.free" />
```gust
def foreign free(addr: integer) -> none
```

Release a block previously returned by `alloc`, `alloc_zeroed`, or
`resize`. A `NULL_ADDRESS` is ignored.

**Parameters**

- `addr: integer` — Address to release.

<Warning>
Using the address after `free`, or freeing the same block twice, is
undefined behavior.
</Warning>

**Parameters**

<a id="unsafe.compare" />
```gust
def foreign compare(a: integer, b: integer, count: integer) -> integer
```

Compare `count` bytes at `a` and `b`. Returns a negative value, zero,
or a positive value when the first differing byte at `a` is respectively
less than, equal to, or greater than the one at `b`.

**Parameters**

- `a: integer` — First address.
- `b: integer` — Second address.
- `count: integer` — Number of bytes to compare.

<Warning>
No bounds checking: reading past either allocation is undefined
behavior.
</Warning>

<a id="unsafe.call1" />
```gust
def foreign call1(fn: integer, arg: integer) -> none
```

Invoke the function at address `fn` with the single pointer-width
argument `arg`. The target must have the C shape `void (*)(void *)` —
the shape of a runtime destructor.

**Parameters**

- `fn: integer` — Function address, e.g. obtained from `c_symbol_address`.
- `arg: integer` — Value passed to the target as a pointer-width word.

<Warning>
Calling an address that is not a function, or one whose signature
does not match, is undefined behavior.
</Warning>

<a id="unsafe.sort" />
```gust
def foreign sort(
    base: integer,
    count: integer,
    elem_size: integer,
    compare: integer,
) -> none
```

Sort `count` elements of `elem_size` bytes at `base` in place, ordering
by the comparison function at address `compare`. The target must have the
C shape `int (*)(const void *, const void *)`, receiving the addresses of
two elements and returning a negative, zero, or positive value.

**Parameters**

- `base: integer` — Address of the first element.
- `count: integer` — Number of elements.
- `elem_size: integer` — Byte size of one element.
- `compare: integer` — Comparison function address, e.g. from `c_symbol_address`.

<Warning>
Calling with a `compare` address that is not a function of the
required shape, or a region smaller than `count * elem_size` bytes,
is undefined behavior.
</Warning>
