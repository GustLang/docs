```gust
use i2c
```

Cross-platform I2C bus access through one neutral API with a backend per
platform:

- Linux: the `/dev/i2c-<bus>` character devices via I2C_RDWR ioctls.
- Raspberry Pi Pico (freestanding / Pico SDK): the `hardware_i2c` block.
- ESP32 (ESP-IDF): the `driver/i2c.h` master driver.

Targets with no user-space I2C bus — macOS, Windows, the browser — have no `i2c`
package: an import there resolves to nothing and every reference is a compile
error.

Addresses are 7-bit. Byte values are plain `integer`s truncated to a byte.

A driver for a device on the bus — a sensor, an EEPROM, a display controller —
takes a `Bus` rather than a bus index, so the same driver runs against a real
controller on one board and against whatever else implements the interface on
the next.

**Examples**

```gust
use i2c

def main() -> none
    bus := i2c.controller(1)
    if not bus.ok()
        return
    end
    # Select register 0x00 on the device at address 0x40, then read 2 bytes.
    data := bus.write_read(0x40, [0x00], 2)
    print(f"read {data.length} bytes")
    bus.close()
end
```

<Note>
Only available where `os == "linux" or has("i2c")`.
</Note>

## `Controller`

<a id="Controller" />
An I2C bus held open for transfers.

**Implements:** [`Bus`](#Bus)

```gust
def Controller implements Bus

    handle: integer

end
```

**Fields**

- `handle: integer` — The backend's bus handle, or -1 if the bus could not be opened.

**Methods**

<a id="Controller.ok" />
```gust
def Controller.ok() -> bool
```

Whether the bus was opened successfully.

---

<a id="Controller.write" />
```gust
def Controller.write(addr: integer, data: list[integer]) -> integer
```

Write the bytes in `data` to 7-bit address `addr`. Returns 0 on
success, non-zero on NACK/error.

**Parameters**

- `addr` — 7-bit target device address.
- `data` — Bytes to write (each truncated to a byte).

---

<a id="Controller.read" />
```gust
def Controller.read(addr: integer, count: integer) -> list[integer]
```

Read `count` bytes from 7-bit address `addr`. Returns the bytes as a
list (empty on error).

**Parameters**

- `addr` — 7-bit target device address.
- `count` — Number of bytes to read.

---

<a id="Controller.write_read" />
```gust
def Controller.write_read(
    addr: integer,
    data: list[integer],
    count: integer,
) -> list[integer]
```

Write `data` then read `count` bytes from `addr` in one transaction
(repeated START, no STOP in between) — the usual "select register, read
it back" pattern. Returns the bytes read (empty on error).

**Parameters**

- `addr` — 7-bit target device address.
- `data` — Bytes to write before the read.
- `count` — Number of bytes to read back.

---

<a id="Controller.close" />
```gust
def Controller.close() -> none
```

Release the bus. Transferring on it afterwards is an error, not a
crash.

## `Bus`

<a id="Bus" />
A byte-addressed I2C bus a device can be talked to over.

A driver names this as the type of the bus its device sits on instead of
naming a controller index, so it binds to the contract rather than to a
chip. `Controller` is the implementation backed by real hardware.

**Implemented by:** [`Controller`](#Controller)

## Functions

<a id="i2c.configure" />
```gust
def foreign configure(
    bus: integer,
    sda: integer,
    scl: integer,
    baud_khz: integer,
) -> none
```

Embedded only: pin-mux `sda`/`scl` and set the bus speed for `bus`
before calling `controller`. On hosted platforms the bus pins and clock are
owned by the OS/kernel (device tree), so this is a no-op — `controller`
picks them up from the system. Call this once, before `controller`, on the
Pico when the device is wired to non-default GPIOs (e.g. I2C1 on GP6/GP7).

**Parameters**

- `bus: integer` — I2C bus / controller index.
- `sda: integer` — GPIO number for the SDA line.
- `scl: integer` — GPIO number for the SCL line.
- `baud_khz: integer` — Bus speed in kHz.

---

<a id="i2c.controller" />
```gust
def controller(index: integer) -> Controller
```

Open I2C controller `index` (Linux: `/dev/i2c-<index>`; Pico: controller
0 or 1). On the Pico the bus is brought up using the pins/speed from a prior
`configure`, falling back to the board default SDA/SCL at 400 kHz.

Check `ok` before transferring on it: a bus that could not be opened is
returned closed rather than raising, so a program can fall back.

**Parameters**

- `index: integer` — I2C bus / controller index.
