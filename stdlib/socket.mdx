```gust
use socket
```

Thin TCP socket primitives over POSIX sockets, with no external dependencies.

This package exposes the raw connect / listen / accept / send / recv plumbing so
that byte-stream protocols can be written in Gust itself rather than in C. It is
the layer the `http` and `websockets` packages are built on.

Handles are plain file descriptors. `connect` and `listen` are the entry points;
`Listener.accept` yields a `Socket`, and a `Socket` carries the send/recv methods.
All operations raise `IOError` on a socket-level failure.

Plaintext only — there is no TLS here. `wss://` / `https://` need a TLS layer
wrapping these sockets; the `ssl` package provides exactly that.

**Examples**

```gust
use socket

def main() -> none
    conn := socket.connect("example.com", 80)
    conn.send("GET / HTTP/1.0\r\nHost: example.com\r\n\r\n")
    reply := conn.recv_string(4096)
    print(reply)
    conn.close()
end
```

<Note>
Only available on native builds.
</Note>

## `Socket`

<a id="Socket" />
<Note>
Only available where `target == "native" or has("sockets")`.
</Note>

A connected TCP socket.

Obtain one from `connect(host, port)` (client side) or `Listener.accept()`
(server side). `recv` returning empty `bytes` means the peer closed the
connection.

**Implements:** [`Stream`](#Stream)

```gust
def Socket implements Stream

    _fd: integer
    _open: bool

end
```

**Fields**

- `_fd: integer` — The underlying file descriptor.
- `_open: bool` — False once `close()` has been called locally.

**Methods**

<a id="Socket.send" />
```gust
def Socket.send(text: string) -> none
```

Send `text` in full, looping over short writes.

This is for text protocols: the string is sent up to its first NUL byte. For
arbitrary binary data (which may contain NULs) use `send_bytes`.

**Parameters**

- `text` — The text to send.

**Raises**

- `IOError` — If the connection drops mid-send.

---

<a id="Socket.send_bytes" />
```gust
def Socket.send_bytes(data: bytes) -> none
```

Send every byte of `data` in full, looping over short writes. Length-aware,
so embedded NUL bytes are sent correctly.

**Parameters**

- `data` — The raw bytes to send.

**Raises**

- `IOError` — If the send fails.

---

<a id="Socket.recv" />
```gust
def Socket.recv(max: integer) -> bytes
```

Read whatever bytes are available now, up to `max`, and return them.

Blocks until at least one byte arrives, then returns immediately — it does
not wait for `max` bytes. An empty result means the peer closed the
connection (EOF); use that to end a read loop. At most 16 MiB is returned
per call regardless of `max`.

**Parameters**

- `max` — Maximum number of bytes to read in this call.

**Raises**

- `IOError` — On a socket error.

---

<a id="Socket.recv_string" />
```gust
def Socket.recv_string(max: integer) -> string
```

Like `recv`, but decode the bytes as a string. Convenient for text
protocols; an empty string means EOF.

**Parameters**

- `max` — Maximum number of bytes to read in this call.

**Raises**

- `IOError` — On a socket error.

---

<a id="Socket.recv_exact" />
```gust
def Socket.recv_exact(n: integer) -> bytes
```

Read exactly `n` bytes, looping until all of them arrive, and return them.

Useful for framed protocols where the next field's length is known (e.g. a
fixed-size frame header).

**Parameters**

- `n` — The exact number of bytes to read.

**Raises**

- `IOError` — If the peer closes before `n` bytes have been read.

---

<a id="Socket.wait_readable" />
```gust
def Socket.wait_readable(timeout_ms: integer) -> bool
```

Wait until a `recv` on this socket would return without blocking, or
until `timeout_ms` elapses. False means the timeout won.

End of stream counts as readable: a `recv` on a peer that closed returns
empty bytes at once. This is what an event loop drives a connection with —
test readability, then read only when something is waiting.

**Parameters**

- `timeout_ms` — Milliseconds to wait; 0 polls, negative waits indefinitely.

---

<a id="Socket.close" />
```gust
def Socket.close() -> none
```

Close the socket. Idempotent — closing an already-closed socket is a
no-op.

---

<a id="Socket.is_open" />
```gust
def Socket.is_open() -> bool
```

True while the socket has not been closed locally. This does not detect a
peer-side close — a `recv` returning empty `bytes` is the signal for that.

---

<a id="Socket.fd" />
```gust
def Socket.fd() -> integer
```

The raw file descriptor, for callers that need to poll it directly.

---

<a id="Socket.peer_ip" />
```gust
def Socket.peer_ip() -> string
```

The remote peer's IP address as text (IPv4 or IPv6), or "" if it
cannot be determined.

## `Stream`

<a id="Stream" />
<Note>
Only available where `target == "native" or has("sockets")`.
</Note>

A bidirectional byte stream — the shared surface of `socket.Socket`
and `ssl.SSLSocket`.

Protocol layers (`http`, `websockets`) take a `Stream` rather than a
concrete socket type, so the same code drives a plaintext `ws://`/`http://`
connection or a TLS `wss://`/`https://` one depending on which value is
handed in. `recv` returning empty `bytes` always means the peer closed.

## Functions

<a id="socket.connect" />
```gust
def connect(host: string, port: integer) -> Socket
```

<Note>
Only available where `target == "native" or has("sockets")`.
</Note>

Open a TCP connection to `host:port` and return the connected socket.

The host is resolved via the system resolver, so a hostname or a literal
IPv4/IPv6 address both work.

**Parameters**

- `host: string` — Hostname or IP address to connect to.
- `port: integer` — TCP port to connect to.

**Raises**

- `IOError` — If resolution or the connection fails.

---

<a id="socket.listen" />
```gust
def listen(port: integer) -> Listener
```

<Note>
Only available where `target == "native" or has("sockets")`.
</Note>

Bind a TCP listening socket on all interfaces at `port` and return it.

`SO_REUSEADDR` is set and the listen backlog is 128.

**Parameters**

- `port: integer` — TCP port to listen on.

**Raises**

- `IOError` — If the socket cannot be created, bound, or put into the listening state.

---

<a id="socket.listen_on" />
```gust
def listen_on(host: string, port: integer) -> Listener
```

<Note>
Only available where `target == "native" or has("sockets")`.
</Note>

Bind a TCP listening socket to `host` at `port` and return it.

`host` names the interface to accept on: `"0.0.0.0"` (or `""`) binds every
interface, `"127.0.0.1"` or `"localhost"` binds the loopback only, and a
specific interface IP restricts the socket to that interface. `SO_REUSEADDR`
is set and the listen backlog is 128.

**Parameters**

- `host: string` — Interface address or hostname to bind; `""` for all interfaces.
- `port: integer` — TCP port to listen on.

**Raises**

- `IOError` — If `host` cannot be resolved, or the socket cannot be created, bound, or put into the listening state.

---

**Parameters**

<a id="socket.set_timeout" />
```gust
def set_timeout(fd: integer, ms: integer) -> none
```

<Note>
Only available where `target == "native" or has("sockets")`.
</Note>

Bound how long a single `recv`/`send` on `fd` may block, in milliseconds.
A stalled call past the timeout raises `IOError`, the same as a hung peer. A
`ms` of 0 clears the timeout, so calls block indefinitely.

**Parameters**

- `fd: integer` — A connected socket file descriptor.
- `ms: integer` — Timeout in milliseconds; 0 to block indefinitely.

---

<a id="socket.raw_open" />
```gust
def raw_open(domain: integer, kind: integer, protocol: integer) -> integer
```

Create a socket in any address family and return its file descriptor.

`connect` and `listen` cover TCP, where a host and a port say everything
about the address. This is the layer beneath them, for protocols whose
addresses only their own specification describes — the caller names the
family, builds the address bytes itself, and passes them to `bind_raw` or
`connect_raw`.

**Parameters**

- `domain: integer` — The address family, e.g. 31 for Bluetooth on Linux.
- `kind: integer` — The socket kind, from `raw_kind` or `sequenced_kind`.
- `protocol: integer` — The protocol within the family, 0 for its default.

**Raises**

- `IOError` — If the family, kind or protocol is unsupported, or the process lacks the privileges the family requires.

---

<a id="socket.bind_raw" />
```gust
def bind_raw(fd: integer, address: bytes) -> none
```

Bind `fd` to a local address, whose bytes are the address structure the
socket's family defines.

**Parameters**

- `fd: integer` — A descriptor from `raw_open`.
- `address: bytes` — The family's address structure, laid out as its specification gives it.

**Raises**

- `IOError` — If the address is malformed, in use, or not permitted.

---

<a id="socket.connect_raw" />
```gust
def connect_raw(fd: integer, address: bytes) -> none
```

Connect `fd` to a peer address, whose bytes are the address structure
the socket's family defines.

On a socket left blocking this returns once the connection is established.
On one made non-blocking by `set_nonblocking` it returns immediately and
the connection is still being made — wait for it with `wait_writable` and
then read `pending_error` to learn whether it succeeded.

**Parameters**

- `fd: integer` — A descriptor from `raw_open`.
- `address: bytes` — The peer's address structure.

**Raises**

- `IOError` — If the address is malformed or the connection is refused.

---

<a id="socket.listen_raw" />
```gust
def listen_raw(fd: integer, backlog: integer) -> none
```

Put a bound socket into the listening state, so `accept_raw` can take
connections from it.

`listen` creates, binds and listens in one step, which it can do because a
TCP address is only a port. This is that last step alone, for a socket the
caller bound itself with `bind_raw`.

**Parameters**

- `fd: integer` — A descriptor from `raw_open`, already bound.
- `backlog: integer` — How many connections may wait to be accepted at once.

**Raises**

- `IOError` — If the socket cannot be made to listen.

---

<a id="socket.accept_raw" />
```gust
def accept_raw(fd: integer) -> integer
```

Take the next connection waiting on a listening socket and return its
descriptor.

Blocks until a connection arrives. Waiting for `fd` to become readable
first, with `os.fd_wait_readable`, is what bounds that wait.

**Parameters**

- `fd: integer` — A listening descriptor from `raw_open` and `listen_raw`.

**Raises**

- `IOError` — If the accept fails.

---

<a id="socket.local_address" />
```gust
def local_address(fd: integer) -> bytes
```

The address `fd` is bound to, as the address structure its family
defines.

A socket bound to an unspecified address or port is assigned a real one by
the kernel, and this is what reads back which one it got.

**Parameters**

- `fd: integer` — A bound socket descriptor.

**Raises**

- `IOError` — If the descriptor is not a bound socket.

---

<a id="socket.peer_address" />
```gust
def peer_address(fd: integer) -> bytes
```

The address of the peer `fd` is connected to, as the address structure
its family defines. This is how an accepted connection says who reached it.

**Parameters**

- `fd: integer` — A connected socket descriptor.

**Raises**

- `IOError` — If the descriptor is not a connected socket.

---

<a id="socket.set_nonblocking" />
```gust
def set_nonblocking(fd: integer, on: bool) -> none
```

Put `fd` into non-blocking mode, or take it out again. A non-blocking
socket never waits: an operation that would block reports that instead.

**Parameters**

- `fd: integer` — An open socket descriptor.
- `on: bool` — True to stop the socket blocking, false to let it block again.

**Raises**

- `IOError` — If the descriptor is not open.

---

<a id="socket.wait_writable" />
```gust
def wait_writable(fd: integer, timeout_ms: integer) -> bool
```

Wait until `fd` can be written without blocking, or until `timeout_ms`
elapses. False means the timeout won.

A connection in progress on a non-blocking socket completes by becoming
writable, which is what makes this the other half of `connect_raw` there.

**Parameters**

- `fd: integer` — An open socket descriptor.
- `timeout_ms: integer` — Milliseconds to wait; 0 polls, negative waits indefinitely.

---

<a id="socket.pending_error" />
```gust
def pending_error(fd: integer) -> integer
```

Take the error the socket recorded, or 0 when it recorded none. This is
how a connection started on a non-blocking socket reports its outcome once
`wait_writable` says it finished.

**Parameters**

- `fd: integer` — An open socket descriptor.

---

<a id="socket.error_text" />
```gust
def error_text(code: integer) -> string
```

Describe the error `pending_error` returned.

**Parameters**

- `code: integer` — An error number.

---

<a id="socket.raw_kind" />
```gust
def raw_kind() -> integer
```

The socket kind that hands the protocol's own packets straight through,
for `raw_open`. A family's control channel usually wants this.

---

<a id="socket.sequenced_kind" />
```gust
def sequenced_kind() -> integer
```

The socket kind that preserves message boundaries on a connection, for
`raw_open`.

---

<a id="socket.stream_kind" />
```gust
def stream_kind() -> integer
```

The socket kind that carries a connection as one continuous byte stream,
for `raw_open`. What is written arrives in order, but not necessarily in the
same number of pieces it was sent in.
