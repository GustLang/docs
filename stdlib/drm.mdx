```gust
use drm
```

Tear-free display output through the Linux kernel mode-setting interface
(DRM/KMS, `/dev/dri/card<index>`). Unlike a raw framebuffer, this owns the
display: it enumerates the connected monitor, sets its video mode, and presents
frames with double-buffered page-flips synchronized to the vertical refresh, so
the screen never tears or shows a half-drawn frame.

`open` finds the first connected output, allocates two dumb buffers in the
XRGB8888 format, and begins scanning out. All drawing lands in an off-screen
back buffer; `flush` page-flips it onto the display and blocks until the flip
completes at the next vblank, then swaps buffers. A UI redraws the full frame
each iteration and calls `flush` to present it.

Colors are 24-bit `0xRRGGBB` integers, stored directly as XRGB8888 pixels.

Linux only — the package exists on no other target, so an import elsewhere is
a compile error. Requires DRM master: no window system or compositor may own
the display (a bare console the program takes over, or a device with the
console detached from the card). A `Display` that could not acquire the screen
is returned closed rather than raising — check `ok`, and the drawing calls are
no-ops either way.

**Examples**

```gust
use drm

def main() -> none
    screen := drm.open(0)
    if not screen.ok()
        return
    end
    screen.clear(0x101828)
    screen.fill_rect(20, 20, 200, 80, 0x3B82F6)
    screen.flush()
    screen.close()
end
```

<Note>
Only available on Linux.
</Note>

## `Display`

<a id="Display" />
A display this program is scanning out to, and its off-screen back
buffer.

Drawing calls target the back buffer; `flush` presents it. Calls on a
closed display are no-ops, and the geometry queries report 0.

```gust
def Display

    handle: integer

end
```

**Fields**

- `handle: integer` — The acquired display, or -1 if it could not be acquired.

**Methods**

<a id="Display.ok" />
```gust
def Display.ok() -> bool
```

Whether the display was acquired successfully.

---

Width of the active video mode in pixels, or 0 if it is not open.

---

<a id="Display.height" />
```gust
def Display.height() -> integer
```

Height of the active video mode in pixels, or 0 if it is not open.

---

<a id="Display.bpp" />
```gust
def Display.bpp() -> integer
```

Bits per pixel of the presented buffers — always 32 for XRGB8888, or 0
if it is not open.

---

<a id="Display.clear" />
```gust
def Display.clear(rgb: integer) -> none
```

Fill the entire back buffer with `rgb`. Not visible until `flush`.

**Parameters**

- `rgb` — Color as `0xRRGGBB`.

---

<a id="Display.set_pixel" />
```gust
def Display.set_pixel(x: integer, y: integer, rgb: integer) -> none
```

Set the pixel at (`x`, `y`) to `rgb` in the back buffer. Coordinates
outside the display are ignored. Not visible until `flush`.

**Parameters**

- `x` — Column, 0 at the left.
- `y` — Row, 0 at the top.
- `rgb` — Color as `0xRRGGBB`.

---

<a id="Display.fill_rect" />
```gust
def Display.fill_rect(
    x: integer,
    y: integer,
    w: integer,
    h: integer,
    rgb: integer,
) -> none
```

Fill the `w`x`h` rectangle whose top-left is (`x`, `y`) with `rgb` in the
back buffer. The rectangle is clipped to the display. Not visible until
`flush`.

**Parameters**

- `x` — Left edge column.
- `y` — Top edge row.
- `w` — Rectangle width in pixels.
- `h` — Rectangle height in pixels.
- `rgb` — Color as `0xRRGGBB`.

---

<a id="Display.flush" />
```gust
def Display.flush() -> none
```

Present the back buffer: page-flip it onto the display, block until the
flip completes at the next vertical refresh, then swap buffers so subsequent
drawing targets the newly hidden buffer.

The freshly exposed back buffer still holds the frame before last, so a
caller that does not redraw the whole frame each time should `clear` first.

---

<a id="Display.close" />
```gust
def Display.close() -> none
```

Restore the display's prior mode, release the buffers, and drop DRM
master. Drawing calls after this are no-ops.

## Functions

<a id="drm.open" />
```gust
def open(index: integer) -> Display
```

Open `/dev/dri/card<index>`, acquire the first connected display, set its
preferred video mode, and begin double-buffered scanout. Both buffers start
black.

A card that is missing, cannot be opened for lack of permission, has no
connected display, or is held by another DRM master yields a closed
`Display` rather than raising — check `ok`.

**Parameters**

- `index: integer` — DRM card index (0 for `/dev/dri/card0`).
