```gust
use images
```

Self-contained image processing with no external runtime dependency, backed
by the public-domain stb headers vendored in this package. Decoding covers PNG,
JPEG, BMP, GIF (first frame), TGA, PSD, HDR, and PNM; encoding covers PNG,
JPEG, BMP, and TGA. Images are 8-bit/channel in mode `L`, `LA`, `RGB`, or
`RGBA`. Operations work on file paths and include creating, saving,
resizing, thumbnailing, cropping, rotating, mode conversion, grayscale, and
blur, plus orientation queries on the `Image` metadata type.

Decoding, encoding, and resizing run through the stb libraries; every other
operation — channel conversion, colour fill, luma, sampling, blur, crop, and
rotate — runs in pure Gust over the decoded pixels.

**Examples**

```gust
use images

def main() -> none
    img := images.open("photo.png")
    print(f"{img.width}x{img.height}")   # e.g. 1920x1080
    images.thumbnail("photo.png", "thumb.png", 128, 128)
end
```

## `Image`

<a id="Image" />
Metadata for an image on disk. Operations return a fresh `Image`
describing the output path.

```gust
def Image

    path: string
    width: integer
    height: integer
    mode: string
    format: string

end
```

**Fields**

- `path: string` — Filesystem path to the image.
- `width: integer` — Image width in pixels.
- `height: integer` — Image height in pixels.
- `mode: string` — Pixel mode (`L`, `LA`, `RGB`, or `RGBA`).
- `format: string` — Image format (e.g. `PNG`, `JPEG`).

**Methods**

<a id="Image.aspect_ratio" />
```gust
def Image.aspect_ratio() -> float
```

Return `width / height`, or `0.0` for an empty image.

---

<a id="Image.is_landscape" />

def Image.is_landscape() -> bool

True when the image is wider than it is tall.

---

<a id="Image.is_portrait" />
```gust
def Image.is_portrait() -> bool
```

True when the image is taller than it is wide.

---

<a id="Image.is_square" />
```gust
def Image.is_square() -> bool
```

True when width and height are equal.

<a id="images.new_image" />
```gust
def new_image(
    path: string,
    width: integer,
    height: integer,
    mode: string,
    color: string,
) -> Image
```

Create a new image filled with `color` and write it to `path`.

**Parameters**

- `path: string` — Destination filesystem path.
- `width: integer` — Image width in pixels.
- `height: integer` — Image height in pixels.
- `mode: string` — Pixel mode (`L`, `LA`, `RGB`, or `RGBA`).
- `color: string` — Fill color — a named color (`"white"`, `"red"`, `"transparent"`, …), hex (`"#336699"`, `"#RRGGBBAA"`), or `"rgb(r, g, b)"` / `"rgba(r, g, b, a)"`.

<a id="images.encode" />
```gust
def encode(
    pixels: bytes,
    width: integer,
    height: integer,
    mode: string,
    dst: string,
    format: string,
) -> Image
```

Encode raw pixel bytes to an image file.

**Parameters**

- `pixels: bytes` — Row-major 8-bit pixel bytes, `width` × `height` × the channel count implied by `mode`.
- `width: integer` — Image width in pixels.
- `height: integer` — Image height in pixels.
- `mode: string` — Pixel mode (`L`, `LA`, `RGB`, or `RGBA`).
- `dst: string` — Destination path to write.
- `format: string` — Output format (`"PNG"`, `"JPEG"`, `"BMP"`, or `"TGA"`); pass `""` to infer it from the `dst` extension.
