```gust
use images
```

Self-contained image processing with no external runtime dependency, backed
by the public-domain stb headers vendored in this package. Decoding covers PNG,
JPEG, BMP, GIF (first frame), TGA, PSD, HDR, and PNM; encoding covers PNG,
JPEG, BMP, and TGA. Images are 8-bit/channel in mode `L`, `LA`, `RGB`, or
`RGBA`.

`open` decodes a file into an `Image` holding its pixels. Every operation —
resize, thumbnail, crop, rotate, mode conversion, grayscale, and blur — is a
method returning a new `Image`, so a pipeline runs entirely in memory and
touches the disk once, at the closing `save`. Use `info` when only a file's
dimensions and format are wanted: it reads the header without decoding.

Decoding, encoding, and resizing run through the stb libraries; every other
operation — channel conversion, colour fill, luma, sampling, blur, crop, and
rotate — runs in pure Gust over the decoded pixels.

**Examples**

```gust
use images

def main() -> none
    img := images.open("photo.png")
    print(f"{img.width}x{img.height}")   # e.g. 1920x1080
    img.thumbnail(128, 128).grayscale().save("thumb.png")
end
```

The stb decoders keep their scratch state in thread-local storage and the
package reads and writes whole files, neither of which the TI calculators
have, so it does not exist on that family.

<Note>
Only available where `family != "ti"`.
</Note>

## `Image`

<a id="Image" />
A decoded image: its pixels and the geometry describing them.

Obtain one from `open`, `new_image`, or `from_pixels`. Operations return a
new `Image` and never modify the receiver, so an intermediate result can be
reused. `save` writes the pixels to disk.

```gust
def Image

    pixels: bytes
    width: integer
    height: integer
    channels: integer

end
```

**Fields**

- `pixels: bytes` — Row-major 8-bit pixel bytes, `width` × `height` × `channels`.
- `width: integer` — Image width in pixels.
- `height: integer` — Image height in pixels.
- `channels: integer` — Bytes per pixel — 1 (`L`), 2 (`LA`), 3 (`RGB`), or 4 (`RGBA`). `mode` reports the same thing as a name.

**Methods**

<a id="Image.mode" />
```gust
def Image.mode() -> string
```

The pixel mode name — `L`, `LA`, `RGB`, or `RGBA`.

---

def Image.aspect_ratio() -> float

Return `width / height`, or `0.0` for an empty image.

True when the image is taller than it is wide.

<a id="Image.is_square" />
```gust
def Image.is_square() -> bool
```

---

<a id="Image.resize" />
```gust
def Image.resize(new_width: integer, new_height: integer) -> Image
```

Resample to exactly `new_width` × `new_height`, ignoring aspect ratio.

**Parameters**

- `new_width` — Target width in pixels.
- `new_height` — Target height in pixels.

**Raises**

- `ValueError` — Either dimension is zero or negative.

---

<a id="Image.thumbnail" />
```gust
def Image.thumbnail(max_width: integer, max_height: integer) -> Image
```

Resample to fit inside `max_width` × `max_height` while preserving the
aspect ratio. An image already within the bounds is returned unscaled.

**Parameters**

- `max_width` — Maximum width in pixels.
- `max_height` — Maximum height in pixels.

---

<a id="Image.crop" />
```gust
def Image.crop(
    left: integer,
    top: integer,
    right: integer,
    bottom: integer,
) -> Image
```

Copy the rectangle `[left, top, right, bottom)` into a new image. The box
is clamped to the image bounds.

**Parameters**

- `left` — Left edge (inclusive) in pixels.
- `top` — Top edge (inclusive) in pixels.
- `right` — Right edge (exclusive) in pixels.
- `bottom` — Bottom edge (exclusive) in pixels.

**Raises**

- `ValueError` — The box is empty after clamping.

---

<a id="Image.rotate" />
```gust
def Image.rotate(degrees: float, expand: bool) -> Image
```

Rotate counter-clockwise with bilinear resampling.

**Parameters**

- `degrees` — Rotation angle in degrees.
- `expand` — When true, grow the canvas enough to hold the rotated image; when false, keep the original dimensions and clip the corners.

---

<a id="Image.convert" />
```gust
def Image.convert(to_mode: string) -> Image
```

Convert to a different pixel mode. Converting to a mode the image is
already in returns it unchanged.

**Parameters**

- `to_mode` — Target mode — `L`, `LA`, `RGB`, or `RGBA`.

**Raises**

- `ValueError` — `to_mode` is not a known mode name.

---

<a id="Image.grayscale" />
```gust
def Image.grayscale() -> Image
```

Convert to single-channel luma (mode `L`).

---

<a id="Image.blur" />
```gust
def Image.blur(radius: float) -> Image
```

Apply a Gaussian blur. A radius of zero or less returns the image
unchanged.

**Parameters**

- `radius` — Blur radius in pixels.

---

<a id="Image.save" />
```gust
def Image.save(dst: string, format: string) -> string
```

Encode the pixels to `dst` and return the canonical format written.

Saving to a format with no alpha channel drops the alpha automatically:
`LA` becomes `L` and `RGBA` becomes `RGB`.

**Parameters**

- `dst` — Destination path to write.
- `format` — Output format — `PNG`, `JPEG`, `BMP`, or `TGA`. Empty infers it from the `dst` extension.

**Raises**

- `IOError` — The format is unknown, cannot be inferred, or the write fails.

## `ImageInfo`

<a id="ImageInfo" />
What a file's header says about the image in it, read without decoding
the pixels. Obtain one from `info`.

```gust
def ImageInfo

    path: string
    width: integer
    height: integer
    mode: string
    format: string

end
```

**Fields**

- `path: string` — Filesystem path the metadata was read from.
- `width: integer` — Image width in pixels.
- `height: integer` — Image height in pixels.
- `mode: string` — Pixel mode the file stores (`L`, `LA`, `RGB`, or `RGBA`).
- `format: string` — Image format inferred from the path extension (e.g. `PNG`).

**Methods**

<a id="ImageInfo.aspect_ratio" />
```gust
def ImageInfo.aspect_ratio() -> float
```

Read an image file's dimensions, mode, and format without decoding its

**Parameters**

- `path: string` — Filesystem path to inspect.

**Raises**

- `IOError` — The file is missing or not a supported image.

---

<a id="images.new_image" />
```gust
def new_image(
    width: integer,
    height: integer,
    mode: string,
    color: string,
) -> Image
```

Create an image of a single solid colour.

**Parameters**

- `width: integer` — Image width in pixels.
- `height: integer` — Image height in pixels.
- `mode: string` — Pixel mode (`L`, `LA`, `RGB`, or `RGBA`).
- `color: string` — Fill color — a named color (`"white"`, `"red"`, `"transparent"`, …), hex (`"#336699"`, `"#RRGGBBAA"`), or `"rgb(r, g, b)"` / `"rgba(r, g, b, a)"`.

**Raises**

- `ValueError` — The mode is unknown, a dimension is not positive, or the colour cannot be parsed.

---

<a id="images.from_pixels" />
```gust
def from_pixels(
    pixels: bytes,
    width: integer,
    height: integer,
    mode: string,
) -> Image
```

Wrap an existing pixel buffer as an `Image` — the entry point for pixels
produced elsewhere, such as a framebuffer snapshot.

**Parameters**

- `pixels: bytes` — Row-major 8-bit pixel bytes, `width` × `height` × the channel count implied by `mode`.
- `width: integer` — Image width in pixels.
- `height: integer` — Image height in pixels.
- `mode: string` — Pixel mode (`L`, `LA`, `RGB`, or `RGBA`).

**Raises**

- `ValueError` — The mode is unknown, or the buffer length does not match the stated geometry.
