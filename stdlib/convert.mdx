Integer base conversions: format an integer as a hex, octal, or binary string
(with the conventional `0x` / `0o` / `0b` prefix) and parse such strings back
to integers, honoring an optional sign and prefix.

Standard base64 and hex codecs live on the built-in string/bytes methods
(`s.encode("base64")`, `s.decode("hex")` → `bytes`, `b.encode("hex")`, etc.) —
all length-aware, so `0x00` octets round-trip. URL percent-encoding lives in the
`url` package. The `base64_url_encode_bytes` wrapper here adds the URL- and
filename-safe alphabet (RFC 4648 §5), which the built-in codec does not.

<a id="convert.hex_digit" />
```gust
def hex_digit(b: integer) -> integer
```

The numeric value 0-15 of an ASCII hex-digit byte (`0`-`9`, `a`-`f`,
`A`-`F`), or -1 if `b` is not a hex digit. The single source of truth for
hex-nibble decoding — `url`, `uuid`, `toml`, and `yaml` all route through
it.

**Parameters**

- `b: integer` — ASCII byte value to decode.

---

<a id="convert.hex_digit_char" />
```gust
def hex_digit_char(ch: string) -> integer
```

The numeric value 0-15 of the single hex-digit character `ch`, or -1
when `ch` is empty or not a hex digit. String-facing companion to
`hex_digit`, which works on a raw byte.

**Parameters**

- `ch: string` — One-character string to decode.

<a id="convert.byte_hex" />
```gust
def byte_hex(b: integer) -> string
```

Format the low byte of `b` (0-255) as two lowercase hex digits — the
encode counterpart to `hex_digit`. Binary-safe (operates on the integer
value, never a NUL-terminable string), so it suits digests and UUIDs.

**Parameters**

- `b: integer` — The byte value to format.

---

<a id="convert.bytes_to_hex" />
```gust
def bytes_to_hex(data: bytes) -> string
```

Lowercase hex of every byte in `data`, e.g. `b"\x0f\xa0"` → `"0fa0"`.
Binary-safe — the single source of truth for hex-encoding a digest, which
is why `cryptography.sha` and `cryptography.hmac` route through it.

**Parameters**

- `data: bytes` — The bytes to hex-encode.

- `base: integer` — Numeric base the digits are in (e.g. 16, 8, 2).
- `pre_lo: string` — Lowercase prefix letter to skip after `0` (e.g. "x", "o", "b").

<a id="convert.parse_int_or" />
```gust
def parse_int_or(s: string, fallback: integer) -> integer
```

Parse a base-10 integer from `s`, honoring an optional leading `+`/`-`
sign and ignoring any non-digit characters. Returns `fallback` when `s`
holds no digits at all. Used for lenient decimal parsing of header values,
port strings, and validated numeric tokens.

**Parameters**

- `s: string` — The string to parse.
- `fallback: integer` — Value to return when `s` contains no digits.

<a id="convert.base64_encode_bytes" />
```gust
def base64_encode_bytes(data: bytes) -> string
```

Standard (RFC 4648) base64 of `data`, with `=` padding. Equivalent to
the built-in `data.encode("base64")`; kept as a function form for callers
that prefer it. Suits digests, keys, and other raw-octet payloads.

**Parameters**

- `data: bytes` — The bytes to encode.

---

<a id="convert.base64_url_encode_bytes" />
```gust
def base64_url_encode_bytes(data: bytes) -> string
```

URL- and filename-safe base64 of `data` (RFC 4648 §5): like
`base64_encode_bytes` but with `-`/`_` substituted for `+`/`/` and the `=`
padding omitted. Suits tokens carried in URLs, cookies, and headers.

**Parameters**

- `data: bytes` — The bytes to encode.
