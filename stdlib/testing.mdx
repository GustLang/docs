```gust
use testing
```

The test context `T` handed to every `@test` function, plus the two control
errors the harness uses to unwind a test early.

Soft failures (`t.fail`, the `expect_*` helpers) accumulate and let the test
keep running so one run surfaces every problem at once. `t.fatal` records a
failure and stops the current test; `t.skip` marks it skipped. Neither affects
the other tests in the file — the harness isolates each one.

A test receives a `T` and reports outcomes through it:

**Examples**

```gust
@test
def parses_port(t: testing.T) -> none
    u := url.parse("http://host:8443/")
    testing.expect_str(t, u.port, "8443", "port")
    if u.scheme != "http"
        t.fatal("scheme parse broke — aborting the rest of this test")
    end
end
```

## `T`

<a id="T" />
The context passed to a `@test` function. Collects the test's failures
and skip state; the harness reads them after the test returns to decide its
outcome.

```gust
def T

    name: string
    failures: list[string]
    skipped: bool
    skip_reason: string

end
```

**Fields**

- `name: string` — the test function's name, used in the report.
- `failures: list[string]` — messages from every soft failure and failed assertion, in order. A non-empty list means the test failed.
- `skipped: bool` — true once `skip` has run.
- `skip_reason: string` — the reason passed to `skip`.

**Methods**

<a id="T.fail" />
```gust
def T.fail(message: string) -> none
```

Record a failure and keep running the test. Use when later checks can
still produce useful output despite this one failing.

**Parameters**

- `message` — the failure description to record.

---

<a id="T.fatal" />
```gust
def T.fatal(message: string) -> none
```

Record a failure and stop the current test immediately. Use when
continuing would cascade into noise or unsafe state.

**Parameters**

- `message` — the failure description to record.

**Raises**

- `FailNowError` — always, to unwind the test after recording the failure.

---

<a id="T.skip" />
```gust
def T.skip(reason: string) -> none
```

Mark the current test skipped and stop running it.

**Parameters**

- `reason` — why the test is skipped, surfaced in the report.

**Raises**

- `SkipError` — always, to unwind the test as skipped.

---

<a id="T.log" />
```gust
def T.log(message: string) -> none
```

Emit a diagnostic line attributed to the current test. The runner shows
it beneath the test when the test fails, or with `--verbose`.

**Parameters**

- `message` — the diagnostic text to emit.

---

<a id="T.failed" />
```gust
def T.failed() -> bool
```

True once any failure has been recorded on this context.

## `TestCase`

<a id="TestCase" />
One registered test: its function `name` and the function itself, which
the harness calls with a fresh `T`.

```gust
def TestCase

    name: string
    fn: Function(T)[none]

end
```

**Fields**

- `name: string` — the test function's name, shown in the report.
- `fn: Function(T)[none]` — the test body, invoked with the test context.

## Errors

<a id="SkipError" />
```gust
error SkipError(message: string)
```

Raised by `T.skip` to unwind the current test as skipped. Caught by the
harness; never propagates to the process.

Fields:
message: the skip reason, surfaced in the report.

---

<a id="FailNowError" />
```gust
error FailNowError(message: string)
```

Raised by `T.fatal` to stop the current test after a failure has already
been recorded. Caught by the harness; never propagates to the process.

Fields:
message: the failure message, already appended to the test's failures.

---

<a id="AssertionError" />
```gust
error AssertionError(message: string)
```

Raised by a failing `assert_*`. The harness records its message and marks
the current test failed.

Fields:
message: the failure description.
