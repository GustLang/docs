AST nodes.

Every Gust syntactic form maps to an ADT variant (for expression and
statement shapes) or a plain struct (for declaration-level nodes where
the field set tends to grow). Walk a tree by matching on the variant:

**Examples**

```gust
match expr
    case IntLit(value, span)
        print(value)
    case Ident(name, line, col)
        print(name)
    else
        pass
end
```

Because a variant pattern may bind a prefix of a variant's fields, an arm
that ignores the trailing `span` still matches.

## `SrcSpan`

<a id="SrcSpan" />
A source location: the half-open character range a node occupies,
given as 1-based `(line, col)` pairs. `end_col` is one past the last
character, so on a single line `end_col - start_col` is the length.

```gust
def SrcSpan

    start_line: integer
    start_col: integer
    end_line: integer
    end_col: integer

end
```

**Fields**

- `start_line: integer`
- `start_col: integer`
- `end_line: integer`
- `end_col: integer`

## `FieldDef`

<a id="FieldDef" />
A struct/error field declaration: its name, declared type, and an
optional default-value expression. `is_private` marks a field that is
only accessible within its defining package (same model as a `private`
function/constant), defaulting to public.

```gust
def FieldDef

    name: string
    ftype: ref[TypeNode]
    has_default: bool
    default_expr: ref[Expr]
    is_private: bool
    is_readonly: bool
    line: integer

end
```

**Fields**

- `name: string`
- `ftype: ref[TypeNode]`
- `has_default: bool`
- `default_expr: ref[Expr]`
- `is_private: bool`
- `is_readonly: bool` — Set by the `readonly` modifier. The field is written at construction and by the declaring struct's own methods; an assignment from anywhere else is rejected.
- `line: integer` — 1-based source line of the field name, or 0 for a field synthesized by the compiler rather than parsed. Read by the `__LINE__` reflection dunder.

## `Import`

<a id="Import" />
A `use` declaration: the imported package `path`, an optional `alias`
(`use pkg as alias`), and `from_names` for the `use (a, b) from pkg`
selective form. `source_file` records the `.g` file the import came from.

`is_path` marks a path-based import (`use "../foo"`): until the package
loader resolves it, `path` holds the raw filesystem path string (relative
to `source_file`) rather than a dotted package name. The loader rewrites
`path` to the clean package name (`alias`) once resolved, so codegen and
ownership treat it like an ordinary name import; `is_path` stays true as
provenance so import lint rules know the `as` alias names the package.

```gust
def Import

    path: string
    alias: string
    line: integer
    from_names: list[string]
    source_file: string
    is_path: bool

end
```

**Fields**

- `path: string`
- `alias: string`
- `line: integer`
- `from_names: list[string]`
- `source_file: string`
- `is_path: bool`

## `FuncSignature`

<a id="FuncSignature" />
A method requirement an interface declares: name, parameters, optional
return type, and an optional docstring. When `has_body` is set the
requirement carries a *default* implementation (`body`) — inherited by any
conforming struct that does not define its own method of the same name.

```gust
def FuncSignature

    name: string
    params: list[Param]
    has_return: bool
    return_type: ref[TypeNode]
    docstring: string
    has_body: bool
    body: list[Stmt]

end
```

**Fields**

- `name: string`
- `params: list[Param]`
- `has_return: bool`
- `return_type: ref[TypeNode]`
- `docstring: string`
- `has_body: bool`
- `body: list[Stmt]` — Default-method body. Empty unless `has_body`; the parser desugars it at parse time, so it is final and may be shared read-only by every struct that inherits the default.

## `StructDef`

<a id="StructDef" />
A struct declaration: its fields, the interfaces it declares conformance

monomorphized at codegen time).

```gust
    is_private: bool
    iface_list: list[string]
    type_params: list[string]
    docstring: string
    parent: string
    decorators: list[Decorator]
    package: string

end
```

**Fields**

- `name: string`
- `fields: list[FieldDef]`
- `line: integer`
- `is_private: bool`
- `iface_list: list[string]`
- `type_params: list[string]`
- `docstring: string`
- `parent: string` — Name of the parent struct in a `def Sub extends Parent` declaration, or "" for a struct with no parent.
- `decorators: list[Decorator]` — Decorators collected from `@name` / `@name(args...)` lines before `def`.
- `package: string` — Package this struct was merged from ("" for user-defined structs in the entry program). Stamped by `merge_package_ast`; the collision pass uses it to mangle a cross-package name clash to `{package}_{name}`.

## `Decorator`

<a id="Decorator" />
A single `@name` or `@name(args...)` decorator attached to a function or
method. `args` holds the (possibly empty) factory-call argument expressions.
The decorated function is always passed first, with `args` appended:
`@retry(3)` lowers to `retry(_impl_fn, 3)`, so a factory is one ordinary
function taking the function plus its arguments.

```gust
def Decorator

    name: string
    args: list[Expr]

end
```

**Fields**

- `name: string`
- `args: list[Expr]`

## `FuncDef`

<a id="FuncDef" />
A free function definition with a body. `type_params` (non-empty)
marks a generic template; `is_async` marks a `def!`.

```gust
def FuncDef

    name: string
    params: list[Param]
    has_return: bool
    return_type: ref[TypeNode]
    body: list[Stmt]
    line: integer
    is_private: bool
    type_params: list[string]
    docstring: string
    is_async: bool
    package: string
    decorators: list[Decorator]
    source_file: string
    signature_end_line: integer
    is_specialization: bool

end
```

**Fields**

- `name: string`
- `params: list[Param]`
- `has_return: bool`
- `return_type: ref[TypeNode]`
- `body: list[Stmt]`
- `line: integer`
- `is_private: bool`
- `type_params: list[string]`
- `docstring: string`
- `is_async: bool` — Set for `def!` — inside this body, consecutive independent calls spawn in parallel (the former auto-parallelizer, now opt-in).
- `package: string` — Package this function was merged from (empty string for user-defined functions in the entry program). Stamped by `Analyzer.merge_package_ast`; codegen uses it to mangle the C symbol to `{package}_{name}` so cross-package calls link.
- `decorators: list[Decorator]` — Decorators collected from `@name` / `@name(args...)` lines before `def`.
- `source_file: string` — The `.g` file this function was parsed from. Lets codegen resolve a qualified-call alias (`cli.foo`) against the imports of the *defining* file rather than the whole merged program, so two files aliasing the same name to different packages don't collide.
- `signature_end_line: integer` — Source line of the signature's last token — the same as `line` unless the parameter list wraps. Diagnostics about a parameter show `line`..`signature_end_line` so the whole signature is visible. 0 for a synthesized function.
- `is_specialization: bool`

## `MethodDef`

<a id="MethodDef" />
A method definition `def Struct.method(...)`: like `FuncDef` but bound
to a receiver struct (`struct_name`). `is_async` marks a `def!` method.

```gust
def MethodDef

    struct_name: string
    method_name: string
    params: list[Param]
    has_return: bool
    return_type: ref[TypeNode]
    body: list[Stmt]
    line: integer
    is_private: bool
    type_params: list[string]
    docstring: string
    is_async: bool
    decorators: list[Decorator]
    package: string
    is_foreign: bool
    source_file: string
    signature_end_line: integer

end
```

**Fields**

- `struct_name: string`
- `method_name: string`
- `params: list[Param]`
- `has_return: bool`
- `return_type: ref[TypeNode]`
- `body: list[Stmt]`
- `line: integer`
- `is_private: bool`
- `type_params: list[string]`
- `docstring: string`
- `is_async: bool` — Set for `def! Name.method(...)`. Same semantics as FuncDef.
- `decorators: list[Decorator]` — Decorators collected from `@name` / `@name(args...)` lines before `def`.
- `package: string` — Package this method was merged from ("" for user code). Stamped by `merge_package_ast`; the collision pass uses it to retarget the method onto its struct's mangled name `{package}_{struct_name}`.
- `is_foreign: bool` — `def foreign Struct.method(...)` — the implementation lives in a linked `.c`; `body` is empty and codegen emits only a prototype, letting the C symbol `Struct_method(Struct* self, ...)` supply the definition. The receiver crosses the FFI boundary as the struct value, so the C side reads its fields directly (no char*↔GStr* param adapter).
- `source_file: string` — The `.g` file this method was parsed from — see `FuncDef.source_file`.
- `signature_end_line: integer` — Source line of the signature's last token — see `FuncDef.signature_end_line`.

## `AliasDef`

<a id="AliasDef" />
A type-alias declaration `type Name = Target`, where `Target` is any
type annotation — most often a union (`Number = integer | float`).

An alias is transparent: it introduces a second spelling for `target`, not
a distinct type. Every reference to `name` in a type position is replaced
by `target` before analysis, so nothing downstream of that substitution
ever sees the alias.

```gust
def AliasDef

    name: string
    target: ref[TypeNode]
    line: integer
    is_private: bool
    docstring: string
    package: string

end
```

**Fields**

- `name: string` — The declared alias name.
- `target: ref[TypeNode]` — The type the alias stands for.
- `line: integer` — Source line of the declaration.
- `is_private: bool` — Whether the declaration is `private`.
- `docstring: string` — The declaration's docstring, if any.
- `package: string` — The owning package, stamped at merge time (empty for a user-program alias). A bare name inside `target` resolves in this package, wherever the alias is referenced from.

## `ConstDef`

<a id="ConstDef" />
A top-level constant declaration `NAME: constant[Type] = value`, or a
foreign one, `foreign NAME: constant[Type]`, whose value is defined in C.

```gust
def ConstDef

    name: string
    ctype: ref[TypeNode]
    value: ref[Expr]
    line: integer
    is_private: bool
    docstring: string
    package: string
    is_foreign: bool
    cfg: string

end
```

**Fields**

- `name: string` — The declared constant name.
- `ctype: ref[TypeNode]` — Its declared type.
- `value: ref[Expr]` — The initializer expression; a `NoneLit` placeholder for a foreign constant, which has none.
- `line: integer` — Source line of the declaration.
- `is_private: bool` — Whether the declaration is `private`.
- `docstring: string` — The declaration's docstring, if any.
- `package: string` — The owning package, stamped at merge time (empty for a user-program constant). Codegen names the constant's C global `<package>_<name>` from it.
- `is_foreign: bool` — Whether the value comes from C: the package's C source defines the global `<package>_<name>` and Gust only declares it.
- `cfg: string` — The predicate of a trailing `#gust:cfg` pragma on the declaration's line, or "" when it carries none. Consumed by the cfg pruning pass, which drops the constant when it is false.


**Fields**

- `imports: list[Import]`
- `errors: list[ErrorDef]`
- `interfaces: list[InterfaceDef]`
- `enums: list[EnumDef]`
- `structs: list[StructDef]`
- `types: list[TypeDef]`
- `aliases: list[AliasDef]`
- `constants: list[ConstDef]`
- `functions: list[FuncDef]`
- `methods: list[MethodDef]`
- `package_funcs: list[FuncDecl]`
- `generic_insts: list[GenericInst]` — Concrete generic-function instantiations discovered by the analyzer. Codegen walks this list to emit one specialization per entry and to rewrite matching call sites to the mangled symbol.
- `generic_struct_insts: list[GenericStructInst]` — Concrete generic-struct instantiations. Same shape as `generic_insts` but keyed on StructDef.name instead of FuncDef.
- `symbol_owner_keys: list[string]` — Package ownership / privacy metadata copied from the analyzer so codegen can answer `dir(pkg)` / private-member questions without re-running semantic analysis.
- `symbol_owner_values: list[string]`
- `private_symbols: list[string]`
- `symbol_source_file_keys: list[string]` — Per-symbol source-file table, copied from the analyzer. Keys mirror `symbol_owner_keys` (bare names for free symbols, `Struct.method` for methods); values are the `.g` file a merged-package decl came from. Entry-program decls are absent (they belong to `source_path`). Lets codegen answer `inspect.file(...)`.
- `symbol_source_file_values: list[string]`
- `source_path: string` — Source path of the entry file. Used for compile-time predefines `__FILE__` / `__NAME__`; populated by the driver before codegen.
- `project_version: string` — `[project].version` from the project's gust.toml, or "" outside a project. Readable at runtime via the `__VERSION__` predefine; populated by the driver before codegen.
- `tracing: bool` — True when the build was invoked with `--trace`, so codegen instruments every generated function body with the trace hook. Readable at compile time via the `__TRACING__` predefine; populated by the driver before codegen.
- `docstring: string` — Module docstring — a leading file-scope docstring (before any declaration), or "" when absent. Readable at runtime via the bare `__DOC__` predefine (alongside `__FILE__` / `__NAME__`).
- `package_doc_keys: list[string]` — Per-package module docstring, keyed by package name. Populated by `merge_package_ast` from each merged package file's leading docstring (the entry program's own doc stays in `docstring`). Lets codegen answer `inspect.doc(pkgalias)` — the package's one-line description for an `autodoc` page header.
- `package_doc_values: list[string]`
- `cfg_decl_pred_keys: list[string]` — Conditional-availability predicate per declaration, keyed like `symbol_source_file_keys` (bare name, or `Struct.method`). Populated by the `@cfg` pruning pass from the decorator it consumes. Lets codegen answer `inspect.cfg(...)` so a documentation renderer can state which targets a declaration exists on.
- `cfg_decl_pred_values: list[string]`
- `cfg_file_pred_keys: list[string]` — Conditional-availability predicate per source file, keyed by `.g` path — the file-level `#gust:cfg` pragma that gates the whole translation unit. A declaration with no `@cfg` of its own inherits its file's predicate.
- `cfg_file_pred_values: list[string]`
- `package_dirs: dict[string, string]` — The on-disk directory each loaded package was read from, keyed by package name. Recorded by the loader as it resolves an import, so the link step can find a package's `*.c` backing files without re-resolving the name — which it cannot do for a path import (`use "../lib/lib.g"`), whose package name no longer says where the package lives.
- `from_import_sources: dict[string, string]` — The package each `use <name> from <pkg>` names, keyed `"<importing package>|<name>"` (the empty package is the entry program). Copied from the analyzer so codegen binds a bare call to the same definition the type checker checked it against when several packages export the name.

## `Lexer`

<a id="Lexer" />
Tokenizer state: the source text being scanned plus the running
cursor. `source`/`filename` are the input; `pos` is the byte offset into
`source`, with `line`/`col` tracking the 1-based source position; `out`
accumulates emitted tokens; `frames` is the newline-significance stack
(see `FR_BRACKET`/`FR_BLOCK`) that supersedes a plain bracket counter so
newlines stay significant inside a bracketed lambda body; the
`failed`/`error_*` fields record the first lexing error and where it
occurred; and `pending_pragma` holds a trailing `#gust:cfg` comment until
the newline ending its line is emitted carrying it (see `CFG_PRAGMA`).

```gust
def Lexer

    source: string
    filename: string
    pos: integer
    line: integer
    col: integer
    out: list[Token]
    frames: list[integer]
    failed: bool
    error_msg: string
    error_line: integer
    error_col: integer
    pending_pragma: string

end
```

**Fields**

- `source: string`
- `filename: string`
- `pos: integer`
- `line: integer`
- `col: integer`
- `out: list[Token]`
- `frames: list[integer]`
- `failed: bool`
- `error_msg: string`
- `error_line: integer`
- `error_col: integer`
- `pending_pragma: string`

**Methods**

<a id="Lexer.frame_top" />
```gust
def Lexer.frame_top() -> integer
```

The kind of the innermost open frame (`FR_BRACKET`/`FR_BLOCK`), or 0 when
no frame is open (top level).

---

<a id="Lexer.bracket_depth" />
```gust
def Lexer.bracket_depth() -> integer
```

The number of brackets still open at the cursor — the count of
`FR_BRACKET` frames on the stack. Used after `tokenize` to tell whether
input is incomplete (e.g. the REPL's continuation prompt).

---

<a id="Lexer.newlines_suppressed" />
```gust
def Lexer.newlines_suppressed() -> bool
```

Whether a source newline is currently insignificant — true only when the
innermost open frame is a bracket. A block frame (a bracketed lambda body)
keeps newlines significant, as does top level.

---

<a id="Lexer.update_block_frames" />
```gust
def Lexer.update_block_frames(kw: integer, at_line_start: bool) -> none
```

Maintain the `FR_BLOCK` stack as block keywords stream past, so the
matching `end` of a bracketed lambda re-enables newline suppression at the
right point.

A `def` seen while already inside a bracket or block frame opens a lambda
body (a nested named def is not legal, so any such `def` has a matching
`end`); a block opener (`if`/`for`/`while`/`match`/`try`/`blocking`) at the
start of a line *within* a lambda body opens a nested block; and any `end`
closes the innermost block frame. Top-level declarations push nothing — the
stack stays empty there, so interface method signatures (which have no
`end`) and ordinary `for`/`if` blocks never unbalance it.

**Parameters**

- `kw` — The keyword token kind just emitted.
- `at_line_start` — Whether that keyword was the first token on its line.

Read the contents of a double-quoted string after the opening quote,

<a id="Lexer.read_multiline_string_body" />
```gust
def Lexer.read_multiline_string_body() -> string
```

Read the contents of a triple-quoted ("""...""") string after the
opening delimiter, consuming the closing triple quote, and return the
decoded text. Only `\"` and `\\` are recognized as escapes — they let a
docstring embed a literal quote or `"""` (`\"\"\"`) without closing
the string; every other character (including other backslash sequences) is
kept verbatim. Calls `fail` if unterminated.

---

<a id="Lexer.read_raw_string_body" />
```gust
def Lexer.read_raw_string_body() -> string
```

Read a raw string after r" — backslashes are literal.

A backslash before any character (including ")
passes both characters through verbatim, and only an un-escaped " ends
the literal. So `r"\d+"` yields the 2-char string `\d+`, which is
what regex patterns want.

---

<a id="Lexer.skip_string_literal" />
```gust
def Lexer.skip_string_literal() -> none
```

Advance the cursor past a double-quoted string literal — single- or
triple-quoted, honoring backslash escapes in the single-quoted form — so a
raw scan (a `quote … end` body or a markup region) never miscounts a
delimiter, keyword, or brace that appears inside string text. Assumes the
cursor is on the opening quote and leaves it just past the closing quote.

---

<a id="Lexer.skip_quote_hole" />
```gust
def Lexer.skip_quote_hole() -> none
```

Consume a `${ … }` interpolation hole inside a quote body, brace-depth
aware and skipping strings, so block keywords that are part of the hole's
*expression* (a ternary `if/else`, a comprehension `for`) are never counted
toward the quote's `end`. Assumes the cursor is on the `$` of `${`.

---

<a id="Lexer.read_quote_body" />
```gust
def Lexer.read_quote_body(open_line: integer, open_col: integer) -> string
```

Read a `quote … end` template body after the `quote` keyword, consuming
the matching `end`, and return the raw body text (interpolation `${…}` holes
left intact for the parser). Tracks block depth so an inner `def … end` /
`if … end` is not mistaken for the quote's terminator, and skips string
literals and `#` comments so keywords inside them never count. Calls `fail`
on a body with no closing `end`, pointing at the opener (`open_line`/
`open_col`) rather than end-of-file.

---

<a id="Lexer.read_fstring_body" />
```gust
def Lexer.read_fstring_body() -> string
```

Read the contents of an f-string after the opening quote, consuming the
closing quote, and return the value. Same as `read_string_body` but also
accepts `\{` and `\}` escapes: the backslash is preserved verbatim so the
parser can distinguish an escaped literal brace from an interpolation
delimiter (it unescapes `\{`/`\}` back to `{`/`}` while splitting parts).
A string literal inside an interpolation (`{"; ".join(xs)}`) is copied
through verbatim, escapes included, so its quotes do not end the f-string.
Calls `fail` on an unterminated string or escape.

---

<a id="Lexer.read_multiline_fstring_body" />
```gust
def Lexer.read_multiline_fstring_body() -> string
```

Read the contents of a triple-quoted f-string (f"""...""") after
the opening delimiter, consuming the closing triple quote, and return the raw
interpolation body. Same escape handling as `read_fstring_body` — `\{` and
`\}` are preserved verbatim so the parser can distinguish escaped braces from
interpolation delimiters. Literal newlines pass through unchanged. Calls `fail`
if unterminated.

---

<a id="Lexer.read_bytes_body" />
```gust
def Lexer.read_bytes_body() -> string
```

Read the contents of a byte literal (b"...") after the opening quote,
consuming the closing quote, and return the decoded byte payload. Decodes
escapes eagerly (including `\xNN`) so the token holds the actual bytes.
Rejects non-ASCII source bytes (use `\xNN` for raw octets) and unknown
escapes via `fail`; also fails on an unterminated literal.

The payload is accumulated with string concatenation rather than a
`Buffer`: the buffer's append path is `strlen`-based and would silently
truncate at the first embedded NUL (so `b"\x00\xff"` came back length 1).
`+` on GStr is length-based, so embedded NULs survive.

Consume and return a run of digits valid for `base`, allowing `_`

<a id="Lexer.read_number" />

---

<a id="Lexer.tokenize" />
```gust
def Lexer.tokenize() -> list[Token]
```

Scan the entire source and return the list of tokens. Drives the main
loop: skips whitespace and comments; recognizes newlines (suppressed inside
brackets and collapsed when consecutive), string/f-string/byte/raw-string
literals, triple-quoted strings, numbers, identifiers/keywords, and two-,
single-, and delimiter operators. Always appends a final TT_NEWLINE (unless
one was just emitted) followed by TT_EOF. Stops early and returns the tokens
collected so far if a lexing error sets `failed`; an unrecognized character
triggers `fail`.

<a id="Parser.starts_variant_pattern" />

True when the cursor is at a payload-binding variant pattern — a dotted

<a id="Parser.parse_comparison" />
```gust
def Parser.parse_comparison() -> Expr
```

Parse comparison-level expressions (precedence above the symbolic binary

<a id="Parser.parse_binary" />
```gust

```

Parse a left-associative chain of symbolic binary operators whose

single loop. The operand base is `parse_cast`; recursing on the right with
`prec + 1` is what makes each precedence level left-associative. Replaces
the former per-level ladder (`parse_bit_or` … `parse_multiplication`), so
adding an operator is a one-line `binop_prec` edit.

<a id="Parser.parse_index_or_slice" />
```gust
def Parser.parse_index_or_slice(target: Expr) -> Expr
```

Parse the contents between `[` and `]` applied to `target`, including the

```gust
) -> TopLevel
```

Parse a `def foreign ...` declaration (the `foreign` keyword is current on
entry). Two forms are accepted, distinguished by a `.` after the name:

- `def foreign name(params) -> ret` → a free foreign function (`TLForeign`
  wrapping a `FuncDecl`).
- `def foreign Struct.method(params) -> ret` → a foreign method
  (`TLMethod` wrapping a bodyless `MethodDef` with `is_foreign` set). The
  C symbol `Struct_method(Struct* self, ...)` supplies the implementation.

Both share an optional docstring, and are terminated by `end`.

---

<a id="Parser.parse" />
```gust
def Parser.parse() -> Program
```

Parse a whole source file into a `Program`. Consumes an optional leading
module docstring, then loops over top-level constructs — imports,
error/interface/enum/type-alias declarations, decorated `def`s (routed by
variant into functions/methods/structs/types/package funcs), and constant
definitions — appending each to the appropriate `Program` table. Stops at
EOF or the first failure.

<a id="ast.body_diverges" />

---

<a id="ast.body_reaches_a_call" />
```gust
def body_reaches_a_call(body: list[Stmt]) -> bool
```

Whether running `body` can reach a call — a function or method call, a
`spawn`, a `raise`, or a lambda whose own body could hold one.

What a call may do is unbounded, and that is exactly what a fact about a
receiver's field stops surviving: the field can be rewritten by any method
the code goes on to call, without that method ever being named here. A
stretch of statements this returns false for cannot rewrite anything except
through the writes it spells out, so a fact proved before it still holds
after it.

**Parameters**

- `body: list[Stmt]` — The statements to search.

---

<a id="ast.expr_reaches_a_call" />
```gust
def expr_reaches_a_call(e: Expr) -> bool
```

Whether evaluating `e` can reach a call, at any depth.

A `Lambda` counts: its body is code this expression carries, and the value
may be invoked as soon as it is handed anywhere. A `StructInit` does not —
filling declared fields runs no user code — but each field's value is
searched.

**Parameters**

- `e: Expr` — The expression to search.
