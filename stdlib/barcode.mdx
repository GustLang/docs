```gust
use barcode
```

A pure-Gust barcode encoder: the linear symbologies below, and QR.

Every encoder turns a payload string into a `Barcode` — a symbology name, the
human-readable text, and a *module string*: one character per module where `1`
is a dark bar and `0` is a light space. From that single representation a
`Barcode` renders to plain bits, terminal ASCII, an SVG document, or a Netpbm
(PBM) bitmap, so the same encoded value can be displayed, embedded in a web
page, or saved as an openable image without any external dependency.

Supported symbologies:

```gust
Code 39   — `code39`: digits, upper-case letters and `-. $/+%`, optionally
            with a mod-43 check character. Self-checking, widely scanned.
Code 128  — `code128`: full printable ASCII (code set B); an all-digit even
            length payload is packed two-per-symbol with code set C.
EAN-13    — `ean13`: 12 digits plus a computed check digit.
EAN-8     — `ean8`: 7 digits plus a computed check digit.
UPC-A     — `upca`: 11 digits plus a computed check digit (an EAN-13 with a
            leading zero).
```

QR is two-dimensional, so `qr` hands back a `QrCode` rather than a `Barcode` —
a square grid of modules, rendered by the same four renderers. See `qr.g`.

Malformed input — an unsupported character, a wrong digit count, or a bad
check digit — raises `BarcodeError`.

**Examples**

```gust
use barcode
bc := barcode.ean13("978014300723")
print(bc.to_ascii())
bc.save("svg", "book.svg")
```


**Fields**

## `QrField`

<a id="QrField" />
Arithmetic in GF(256), as the exponential and logarithm tables every
multiplication in it is a pair of lookups into.

```gust
def QrField

    exp: list[integer]
    log: list[integer]

end
```

**Fields**

- `exp: list[integer]` — the powers of the field's primitive element, listed twice over so that a sum of two logarithms never has to be reduced.
- `log: list[integer]` — the inverse of `exp`, indexed by field element.

**Methods**

<a id="QrField.multiply" />
```gust
def QrField.multiply(a: integer, b: integer) -> integer
```

The product of `a` and `b` in the field.

**Parameters**

- `a` — one factor.
- `b` — the other.

---

<a id="QrField.generator" />
```gust
def QrField.generator(degree: integer) -> list[integer]
```

The generator polynomial of the given degree — the product of
`x - a^i` for each `i` below it — as `degree` coefficients from the highest
power down, with the leading 1 left implicit.

The remainder step divides by exactly these coefficients, so the length
matters: a polynomial carrying its leading 1 would produce one correction
codeword too many and shift every one of them.

**Parameters**

- `degree` — how many error-correction codewords the polynomial produces.

---

<a id="QrField.remainder" />
```gust
def QrField.remainder(
    data: list[integer],
    generator: list[integer],
) -> list[integer]
```

The error-correction codewords for one block: `data` as a polynomial,
divided by `generator`, with the remainder handed back.

**Parameters**

- `data` — the block's data codewords.
- `generator` — the generator polynomial for this many correction codewords.

<a id="barcode.code128" />
```gust
def code128(data: string) -> Barcode
```

Encode `data` as Code 128.

An all-digit payload of even length is packed two digits per symbol using
code set C; any other payload uses code set B and must contain only
printable ASCII (byte values 32-126).

**Parameters**

- `data: string` — the payload to encode.

---

<a id="barcode.ean13" />
```gust
def ean13(data: string) -> Barcode
```

Encode 12 digits as EAN-13; the 13th (check) digit is computed and
appended. Passing 13 digits is accepted only if the final digit already
matches the computed check.

**Parameters**

- `data: string` — the 12-digit payload (or 13 digits with a valid check digit).

**Raises**

- `BarcodeError` — when `data` is not 12 or 13 digits, or the supplied 13th check digit is wrong.

<a id="barcode.upca" />

Encode 11 digits as UPC-A; the 12th (check) digit is computed and

- `data: string` — the 11-digit payload (or 12 digits with a valid check digit).

**Raises**

- `BarcodeError` — when `data` is not 11 or 12 digits, or the supplied 12th check digit is wrong.

<a id="barcode.qr" />
```gust
def qr(data: string) -> QrCode
```

Encode `data` as the smallest QR symbol that holds it.

**Parameters**

- `data: string` — what a reader should come away with. Taken as bytes, so anything outside ASCII is encoded as its UTF-8 sequence and costs a byte per unit.

**Raises**

- `BarcodeError` — when `data` is longer than a version 6 symbol holds.

**Examples**

```gust

```

<a id="barcode.qr_format_bits" />
```gust
def qr_format_bits(mask: integer) -> integer
```

The fifteen bits of format information a level M symbol drawn with
`mask` carries: five bits of level and mask, ten of BCH remainder, the
whole exclusive-ored with the specification's constant so that a blank
symbol is not a valid one.

Exposed because it is the one part of a symbol that can be checked against
the specification's own table without a reader.

**Parameters**

- `mask: integer` — which of the eight masks the symbol is drawn with.
