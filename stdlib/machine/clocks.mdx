```gust
use machine.clocks
```

On-chip clock frequencies.

Read the running frequency of each internal clock, and on a target whose system
clock is not fixed at boot, retune it with `set_sys_khz`. Frequencies are
reported in hertz; a clock the chip does not expose reads as 0.

**Examples**

```gust
use machine.clocks

def main() -> none
    print(clocks.sys_hz())          # e.g. 150000000 on the RP2350
    print(clocks.peripheral_hz())
end
```

<Note>
Only available where `has("clocks")`.
</Note>

<a id="machine.clocks.set_sys_khz" />
```gust
def foreign set_sys_khz(khz: integer) -> bool
```

<Note>
Only available where `has("clock-retune")`.
</Note>

Retune the system clock to `khz` kilohertz, returning whether the
frequency was achievable with the available dividers. Peripheral clocks that
derive from the system clock are updated to track it.

Exists only on a target whose system clock can be retuned at run time; on
one whose frequency is fixed at boot, naming it is a compile error.

**Parameters**

- `khz: integer` — Target system frequency in kilohertz.
