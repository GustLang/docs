```gust
use buffer
```

A growable string builder. Use it instead of repeated `s = s + x`
concatenation when assembling a large string in a loop. Construct one with
`new_buffer()`, then `append` to it, read its `length`, materialize its
contents with `to_string`, and reset it with `clear`.

**Examples**

```gust
use buffer

def main() -> none
    b := buffer.new_buffer()
    for i in range(3)
        b.append(f"line {i}\n")
    end
    print(b.to_string())
end
```

## `Buffer`

<a id="Buffer" />
A growable string builder. Construct with `new_buffer()`. Appended
segments are accumulated and joined once when the contents are read, so
building a large string costs one final concatenation instead of one per
append.

```gust
def Buffer

    _parts: list[string]

end
```

**Fields**

- `_parts: list[string]` — Accumulated string segments in append order — don't touch this directly.

**Methods**

<a id="Buffer.close" />

Does nothing. The buffer's storage is managed and reclaimed
automatically; this method remains so existing callers keep compiling.
