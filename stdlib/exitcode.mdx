```gust
use exitcode
```

Standard process exit codes, named as constants. Covers the BSD sysexits.h
range (64-78), common shell and coreutils conventions (0-2, 124, 126-127), and
signal-derived statuses (128 + signal number). Pass one to `exit(code)`
when terminating a program.
