---
title: inspect
description: "Compile-time introspection over your program's own declarations"
---

```gust
use inspect
```

Compile-time introspection over your program's own declarations. Every
call is resolved by the compiler against the parsed program and lowered
to a constant — there is no runtime cost and no runtime type metadata
involved. Arguments are referred to by name: pass a bare function name,
type name, or a `Type.method` reference (not a string).

`item` is typed `Any` because it stands for a declaration, not a value;
the compiler intercepts the call before the argument is evaluated.

The closed set of things an argument can refer to, returned by `kind`.
Compare with `==` or destructure with `match`.

**Examples**

```gust
use inspect

def greet(name: string, loud: bool) -> string
    """Greet someone."""
    ...
end

inspect.doc(greet)          # "Greet someone."
sig := inspect.signature(greet)   # a Signature struct
f"{sig}"                    # "(name: string, loud: bool) -> string"
sig.parameters[0].name      # "name"
sig.parameters[0].annotation # "string"
sig.return_annotation       # "string"
inspect.params(greet)       # ["name", "loud"]
inspect.kind(greet)         # SymbolKind.Function
inspect.fields(SomeStruct)  # ["x", "y"]
inspect.methods(SomeStruct) # ["render", "area"]
inspect.variants(Color)     # ["red", "green", "blue"]
inspect.line(greet)         # 12
inspect.file(greet)         # "src/app.g"
```

```gust
use SymbolKind from inspect
if inspect.kind(item) == SymbolKind.Function ...
```

## `SymbolKind`

<a id="SymbolKind" />
```gust
enum SymbolKind: string
```

What an inspected argument refers to.

**Variants**

- `Function = "function"` — A free or package function.
- `Struct = "struct"` — A struct type.
- `Enum = "enum"` — An enum type.
- `Interface = "interface"` — An interface type.
- `Error = "error"` — An error type.
- `Type = "type"` — An ADT (`type ... end`).
- `Constant = "constant"` — A top-level constant.
- `Package = "package"` — An imported package.
- `Method = "method"` — A `Type.method` reference.

## `Parameter`

<a id="Parameter" />
A single parameter of a function or method: its `name`, its declared
type `annotation` (source-level spelling), and `has_default` flagging
whether the parameter carries a default value.

```gust
def Parameter

    name: string
    annotation: string
    has_default: bool

end
```

**Fields**

- `name: string` — The parameter's name.
- `annotation: string` — The parameter's declared type (source-level spelling).
- `has_default: bool` — True if the parameter carries a default value.

## `Signature`

<a id="Signature" />
The full signature of a callable. `parameters` holds one `Parameter`
per declared parameter, in order, and `return_annotation` is the declared
return type (source-level spelling).

```gust
def Signature

    parameters: list[Parameter]
    return_annotation: string

end
```

**Fields**

- `parameters: list[Parameter]` — One `Parameter` per declared parameter, in order.
- `return_annotation: string` — The declared return type (source-level spelling).

## `DocEntry`

<a id="DocEntry" />
A complete documentation record for one declaration, gathering
everything the per-accessor calls return into a single struct.
`signature` is an empty `Signature` (no parameters, blank return) for
non-callables; `fields` / `field_types` are empty for non-structs;
`variants` is empty for non-enums; `methods` lists a type's method names
(or an interface's signature names), with `method_signatures[i]` /
`method_docs[i]` carrying the matching `name(p: t) -> ret` spelling and
docstring. `const_type` / `const_value` carry a constant's declared type
and source-level value (both empty for non-constants). Produced by
`describe` for one symbol and by `entries` for a whole package.

```gust
def DocEntry

    name: string
    kind: SymbolKind
    doc: string
    signature: Signature
    fields: list[string]
    field_types: list[string]
    methods: list[string]
    variants: list[string]
    line: integer
    file: string
    const_type: string
    const_value: string
    method_signatures: list[string]
    method_docs: list[string]
    enum_base: string
    enum_is_auto: bool
    variant_values: list[string]
    interfaces: list[string]
    decorators: list[string]
    method_decorators: list[list[string]]
    is_private: bool
    is_foreign: bool
    method_is_private: list[bool]
    method_is_foreign: list[bool]
    cfg: string
    method_cfg: list[string]

end
```

**Fields**

- `name: string` — The declaration's name.
- `kind: SymbolKind` — The declaration's `SymbolKind`.
- `doc: string` — The declaration's docstring (empty if undocumented).
- `signature: Signature` — The callable's `Signature` (empty for non-callables).
- `fields: list[string]` — Field names of a struct or error type (empty otherwise).
- `field_types: list[string]` — Field types matching `fields`, in order.
- `methods: list[string]` — A type's method names, or an interface's signature names.
- `variants: list[string]` — Member names of an enum or variant names of an ADT.
- `line: integer` — The source line where the declaration appears.
- `file: string` — The source file the declaration was defined in.
- `const_type: string` — A constant's declared type (empty for non-constants).
- `const_value: string` — A constant's source-level value (empty for non-constants and for a foreign constant, whose value its C source defines).
- `method_signatures: list[string]` — The `name(p: t) -> ret` spelling per entry in `methods`.
- `method_docs: list[string]` — The docstring per entry in `methods`.
- `enum_base: string` — An enum's backing type (`"integer"` / `"string"`); empty otherwise.
- `enum_is_auto: bool` — True for an `auto_enum` (auto-assigned values).
- `variant_values: list[string]` — An enum member's value per entry in `variants` (the explicit value, the member name for a string auto_enum, or the 1-based number for an integer auto_enum); empty for ADT variants.
- `interfaces: list[string]` — The interface names a struct declares conformance to, in declaration order; empty for non-structs.
- `decorators: list[string]` — The decorator names applied to this declaration (e.g. `["static"]`, `["inline"]`), in source order; empty if none.
- `method_decorators: list[list[string]]` — Per entry in `methods`, that method's decorator names — so `"static" in method_decorators[i]` flags an associated function. Empty inner lists for undecorated / interface methods.
- `is_private: bool` — True when the declaration is private (a `def private` declaration or a leading-underscore name). Documentation renderers hide these unless private members are explicitly requested.
- `is_foreign: bool` — True when a function or method is `foreign` (its body lives in linked C); false for every non-callable.
- `method_is_private: list[bool]` — Per entry in `methods`, whether that method is private.
- `method_is_foreign: list[bool]` — Per entry in `methods`, whether that method is `foreign`.
- `cfg: string` — The conditional-compilation predicate the declaration is available under (e.g. `target == "pico" or target == "esp"`), or "" when it exists on every target. Comes from the declaration's own `@cfg` or, failing that, from its file's `#gust:cfg` pragma.
- `method_cfg: list[string]` — Per entry in `methods`, that method's own conditional availability predicate, or "" when it matches the type's.

Classify the argument as a `SymbolKind`: `Function`, `Struct`, `Enum`,

**Parameters**

<a id="inspect.line" />
```gust
def foreign line(item: Any) -> integer
```

The source line where the declaration appears (relative to its own

**Parameters**

- `item: Any` — A declaration reference to inspect.

---

<a id="inspect.cfg" />
```gust
def foreign cfg(item: Any) -> string
```

The conditional-compilation predicate the declaration is available under
— `target == "pico" or target == "esp"`, `os == "linux"`, and so on — or ""
when it exists on every target. A declaration's own `@cfg` wins; without one
it inherits the `#gust:cfg` pragma gating its file.

Building with `--doc-cfg` keeps the declarations excluded for the target
being compiled, so a documentation generator sees a package's whole surface
and can label each part with the targets it exists on.

**Parameters**

- `item: Any` — A declaration reference to inspect.

---

<a id="inspect.file" />
```gust
def foreign file(item: Any) -> string
```

The path of the source file the declaration was defined in. For
declarations in the program being compiled this is the entry file;
for ones pulled in via `use` it is the package's `.g` file.

**Parameters**

- `item: Any` — A declaration reference to inspect.

<a id="inspect.members" />
```gust
def foreign members(item: Any) -> list[string]
```

Every member name of a type (fields plus methods) or the exported
names of a package, followed by the reflection properties the
declaration answers to (`__DOC__`, `__NAME__`, `__FILE__`). The
declaration-only, namespaced form of the built-in `dir` (use
`dir(value)` for a runtime value's members).

**Parameters**

- `item: Any` — A type or package reference.

---

<a id="inspect.describe" />
```gust
def foreign describe(item: Any) -> DocEntry
```

Gather every fact about one declaration into a single `DocEntry`:
its `name`, `kind`, `doc`, `signature` (empty for non-callables),
`fields` / `field_types`, `methods`, `variants`, `line`, and `file`.
The one-call form of the individual accessors — ideal for feeding a
documentation renderer.

**Parameters**

- `item: Any` — A declaration reference to describe.

---

<a id="inspect.entries" />
```gust
def foreign entries(item: Any) -> list[DocEntry]
```

One `DocEntry` per documentable member of `item`. For a package
(`use mypkg; inspect.entries(mypkg)`) that is every public top-level
declaration it exports; for a struct or interface it is each method.
Lets a tool document a whole module without naming each symbol by
hand — the enumeration `members` can't feed back into `describe`.

**Parameters**

- `item: Any` — A package, struct, or interface reference.

<a id="inspect.decorators" />
```gust
def foreign decorators(item: Any) -> list[string]
```

The decorator names applied to a declaration, in source order — for a
function, a `Type.method` reference, or a struct type. Returns `["static"]`
for a `@static` associated function, `["inline"]` for `@inline`, the name of
a user decorator, and so on; empty when the declaration has none. The
idiomatic static check is `"static" in inspect.decorators(Type.method)`.

**Parameters**

- `item: Any` — A function, method, or struct declaration reference.
