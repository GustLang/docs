```gust
use framebuffer
```

Direct pixel access to a Linux framebuffer device (`/dev/fb<index>`), the
surface behind an HDMI, DSI, or SPI-fbdev display when no window system owns
the screen. `open` maps the device and allocates a matching off-screen buffer;
all drawing lands in that buffer and only becomes visible when `flush` (or
`flush_rect`) copies it to the display, so the screen never shows a
half-drawn frame.

Colors are 24-bit `0xRRGGBB` integers. The device's real pixel format
(commonly 16-bit RGB565 or 32-bit XRGB8888) is read at `open` and every color
is converted to it automatically, so callers work in one color space
regardless of the panel.

A `Framebuffer` that could not be acquired is returned closed rather than
raising: check `ok` before drawing, and the drawing calls are no-ops either
way, so a program can run headless without branching on every call.

Linux only — the package exists on no other target, so an import elsewhere is
a compile error.

**Examples**

```gust
use framebuffer as fb

def main() -> none
    screen := fb.open(0)
    if not screen.ok()
        return
    end
    screen.clear(0x101828)
    screen.fill_rect(20, 20, 200, 80, 0x3B82F6)
    screen.flush()
    screen.close()
end
```

<Note>
Only available on Linux.
</Note>

## `Framebuffer`

<a id="Framebuffer" />
A mapped framebuffer device and its off-screen drawing buffer.

Drawing calls target the off-screen buffer; `flush` or `flush_rect` makes
the result visible. Calls on a closed framebuffer are no-ops, and the
geometry queries report 0.

```gust
def Framebuffer

    handle: integer

end
```

**Fields**

- `handle: integer` — The mapped device, or -1 if it could not be acquired.

**Methods**

<a id="Framebuffer.clear" />
```gust
def Framebuffer.clear(rgb: integer) -> none
```

Fill the entire off-screen buffer with `rgb`. Not visible until `flush`.

**Parameters**

- `rgb` — Color as `0xRRGGBB`.

---

<a id="Framebuffer.set_pixel" />
```gust
def Framebuffer.set_pixel(x: integer, y: integer, rgb: integer) -> none
```

Set the pixel at (`x`, `y`) to `rgb` in the off-screen buffer.
Coordinates outside the display are ignored. Not visible until `flush`.

**Parameters**

- `x` — Column, 0 at the left.
- `y` — Row, 0 at the top.
- `rgb` — Color as `0xRRGGBB`.

---

<a id="Framebuffer.fill_rect" />
```gust
def Framebuffer.fill_rect(
    x: integer,
    y: integer,
    w: integer,
    h: integer,
    rgb: integer,
) -> none
```

Fill the `w`x`h` rectangle whose top-left is (`x`, `y`) with `rgb` in
the off-screen buffer. The rectangle is clipped to the display. Not visible
until `flush`.

**Parameters**

- `x` — Left edge column.
- `y` — Top edge row.
- `w` — Rectangle width in pixels.
- `h` — Rectangle height in pixels.
- `rgb` — Color as `0xRRGGBB`.

---

<a id="Framebuffer.flush" />
```gust
def Framebuffer.flush() -> none
```

Copy the whole off-screen buffer to the display, making every prior
drawing call visible at once.

---

<a id="Framebuffer.flush_rect" />
```gust
def Framebuffer.flush_rect(
    x: integer,
    y: integer,
    w: integer,
    h: integer,
) -> none
```

Copy only the `w`x`h` rectangle at (`x`, `y`) from the off-screen buffer
to the display. Cheaper than `flush` when a single region changed. The
rectangle is clipped to the display.

**Parameters**

- `x` — Left edge column.
- `y` — Top edge row.
- `w` — Rectangle width in pixels.
- `h` — Rectangle height in pixels.

---

<a id="Framebuffer.close" />
```gust
def Framebuffer.close() -> none
```

Unmap the device and free the off-screen buffer. Drawing calls after
this are no-ops.

## Functions

<a id="framebuffer.open" />
```gust
def open(index: integer) -> Framebuffer
```

Open and map `/dev/fb<index>`, allocating a matching off-screen buffer
that starts zeroed (black).

A device that is missing, cannot be opened for lack of permission, or uses
an unsupported pixel format yields a closed `Framebuffer` rather than
raising — check `ok`.

**Parameters**

- `index: integer` — Framebuffer device index (0 for `/dev/fb0`).
