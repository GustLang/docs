```gust
use compression
```

Compression, as compress/decompress pairs operating on raw `bytes`. Four
container formats are exposed — three from the DEFLATE family, backed by the
system zlib, and `.xz`, backed by the system liblzma:

- gzip   (RFC 1952) — `gzip_compress` / `gzip_decompress`, the `.gz` wrapper
          with a header and CRC32; what HTTP `Content-Encoding: gzip` uses.
- zlib   (RFC 1950) — `zlib_compress` / `zlib_decompress`, a compact wrapper
          with an Adler-32 check; what `Content-Encoding: deflate` should be.
- raw    (RFC 1951) — `deflate_compress` / `deflate_decompress`, headerless
          DEFLATE with no checksum.
- xz     — `xz_compress` / `xz_decompress`, LZMA2 in the `.xz` container with
          an integrity check. Slower to compress and far heavier on memory
          than the DEFLATE family, and markedly smaller in return; the usual
          choice for a software release or a disk image.

The compress functions take a `level` from 0 (store) to 9 (smallest); pass
`DEFAULT` for the codec's own default, or the `BEST_SPEED` / `BEST_SIZE`
constants. The default-level convenience wrappers `gzip` / `zlib` / `deflate` /
`xz` cover the common case. Decompression raises `RuntimeError` on malformed or
truncated input.

Native builds only: the codecs are the system zlib and liblzma, which the
microcontroller targets and the browser sandbox do not ship. An import there is
a compile error.

**Examples**

```gust
use compression

def main() -> none
    packed := compression.gzip("hello, hello, hello" as bytes)
    text := compression.gzip_decompress(packed) as string
    print(text)                # hello, hello, hello
end
```

<a id="compression.xz_compress" />
```gust
def xz_compress(data: bytes, level: integer) -> bytes
```

Compress `data` to the `.xz` format at the given level.

Levels above 6 raise the memory the *decompressor* needs as well as the
compressor — level 9 asks for a 64 MB dictionary — so a stream meant for a
small device is worth keeping at or below the default.

**Parameters**

- `data: bytes` — The bytes to compress.
- `level: integer` — 0-9 (0 = fastest, 9 = smallest), or `DEFAULT` for the codec's own default of 6.

---

<a id="compression.xz_decompress" />
```gust
def xz_decompress(data: bytes) -> bytes
```

Decompress `.xz`-framed `data`, verifying the container's integrity
check. Concatenated streams are decoded as one, matching the `xz` tool.

**Parameters**

- `data: bytes` — The `.xz` stream to decompress.

**Raises**

- `RuntimeError` — If `data` is not a well-formed `.xz` stream, is truncated, or fails its integrity check.
