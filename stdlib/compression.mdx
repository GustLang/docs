```gust
use compression
```

DEFLATE-family compression backed by the system zlib. Three container formats
are exposed, each as a compress/decompress pair operating on raw `bytes`:

- gzip   (RFC 1952) — `gzip_compress` / `gzip_decompress`, the `.gz` wrapper
          with a header and CRC32; what HTTP `Content-Encoding: gzip` uses.
- zlib   (RFC 1950) — `zlib_compress` / `zlib_decompress`, a compact wrapper
          with an Adler-32 check; what `Content-Encoding: deflate` should be.
- raw    (RFC 1951) — `deflate_compress` / `deflate_decompress`, headerless
          DEFLATE with no checksum.

The compress functions take a `level` from 0 (store) to 9 (smallest); pass
`DEFAULT` for zlib's default, or the `BEST_SPEED` / `BEST_SIZE` constants. The
default-level convenience wrappers `gzip` / `zlib` / `deflate` cover the common
case. Decompression raises `RuntimeError` on malformed or truncated input.

**Examples**

```gust
use compression

def main() -> none
    packed := compression.gzip("hello, hello, hello" as bytes)
    text := compression.gzip_decompress(packed) as string
    print(text)                # hello, hello, hello
end
```

## Constants

| Name | Type | Value |
|------|------|-------|
| `DEFAULT` | `integer` | `-1` |
| `BEST_SPEED` | `integer` | `1` |
| `BEST_SIZE` | `integer` | `9` |
| `WBITS_GZIP` | `integer` | `31` |
| `WBITS_ZLIB` | `integer` | `15` |
| `WBITS_RAW` | `integer` | `-15` |

<a id="compression.gzip_compress" />
```gust
def gzip_compress(data: bytes, level: integer) -> bytes
```

Compress `data` to the gzip (`.gz`) format at the given level.

**Parameters**

- `data: bytes` — The bytes to compress.
- `level: integer` — 0-9 (0 = store, 9 = smallest), or `DEFAULT` for zlib's default.
