```gust
use ansi
```

ANSI terminal escape sequences for colored and styled output. Exposes the
raw SGR constants plus convenience wrappers that wrap a string in a style
and a reset.

**Examples**

```gust
use ansi
print(ansi.red("error: ") + "file not found")
```

**On this page:** [`sgr`](#ansi.sgr) · [`fg_param`](#ansi.fg_param) · [`bg_param`](#ansi.bg_param) · [`red`](#ansi.red) · [`green`](#ansi.green) · [`yellow`](#ansi.yellow) · [`blue`](#ansi.blue) · [`magenta`](#ansi.magenta) · [`cyan`](#ansi.cyan) · [`white`](#ansi.white) · [`bold`](#ansi.bold) · [`dim`](#ansi.dim) · [`italic`](#ansi.italic) · [`underline`](#ansi.underline)

## Functions

<a id="ansi.sgr" />
```gust
def sgr(parts: list[string]) -> string
```

Assemble an SGR escape from numeric `parts` (e.g. `["1", "31"]` →
`"\x1b[1;31m"`). Returns `""` for an empty list so callers can skip
emitting a matching reset.

**Parameters**

- `parts: list[string]` — SGR parameter strings to join with `;`.

---

<a id="ansi.fg_param" />
```gust
def fg_param(color: string) -> string
```

Map a named color to its foreground SGR parameter, or `""` if unknown.
Recognizes the 8 base colors plus their `bright_`/`gray` variants. The
single source of truth for the named-color table (used by `cli`).

**Parameters**

- `color: string` — The named color to map.
