Terminal key decoder: the byte-to-keycode state machine behind `read_key()`
and `read_key_timeout()`.

The reader pulls one byte at a time from stdin through `_read_byte`, a small
timed-read primitive backed by the terminal syscalls in ui.c. A printable or
control byte maps straight to its own code. An ESC byte opens an escape
sequence, and the decoder pulls continuation bytes (each with a short timeout,
so a lone ESC key does not stall) to resolve CSI (`ESC [ ...`) and SS3
(`ESC O ...`) forms into the tagged codes in keys.g.

`_read_byte` returns a byte value in `0..255`, or one of three sentinels that
double as the keycode the reader should yield when no byte is available:
`KEY_NONE` (-1) on EOF or read error, `KEY_TIMEOUT` (-2) when the wait elapses,
and `KEY_RESIZE` (266) when the terminal was resized.

## `Border`

<a id="Border" />
```gust
enum Border: string
```

A border preset, naming the glyph set drawn around a view.

**Variants**

- `off = "none"` — No border.
- `rounded = "rounded"` — Rounded corners (╭╮╰╯).
- `normal = "normal"` — Square single-line corners (┌┐└┘).
- `thick = "thick"` — Heavy single-line box.
- `double = "double"` — Double-line box (╔╗╚╝).
- `ascii = "ascii"` — Plain ASCII (+ - |), for terminals without box-drawing glyphs.
- `block = "block"` — Solid full-block edges.
- `outer_half = "outer_half_block"` — Half-block edges facing outward.
- `inner_half = "inner_half_block"` — Half-block edges facing inward.
- `hidden = "hidden"` — Space glyphs — reserves the border's width without drawing it.
- `markdown = "markdown"` — A Markdown-table-style frame.
