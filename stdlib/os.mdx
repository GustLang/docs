System-level utilities: the operating-system and hardware identity (platform,
OS version, architecture, hostname, byte order), process identity (pid, ppid,
uid, username, executable path, command-line arguments), standard-stream I/O,
executable lookup on `$PATH`, and a per-compile arena allocator for batch
drivers.

**Examples**

```gust
use os

def main() -> none
    print(os.hostname())
    print(os.pid())
end
```

## `Platform`

<a id="Platform" />
```gust
auto_enum Platform: string
```

Operating-system family the binary is running on.

**Variants**

- `linux = "linux"` — Linux kernel
- `macos = "macos"` — macOS / Darwin
- `windows = "windows"` — Microsoft Windows
- `android = "android"` — Android
- `freebsd = "freebsd"` — FreeBSD
- `openbsd = "openbsd"` — OpenBSD
- `netbsd = "netbsd"` — NetBSD
- `cygwin = "cygwin"` — Cygwin environment on Windows
- `solaris = "solaris"` — Solaris / illumos
- `hpux = "hpux"` — HP-UX
- `unix = "unix"` — Generic Unix-like, family not otherwise identified
- `emscripten = "emscripten"` — WebAssembly (browser or Node) runtime profile
- `freestanding = "freestanding"` — Bare-metal target with no operating system
- `unknown = "unknown"` — Platform could not be determined

<a id="os.arena_push" />
```gust
def foreign arena_push() -> none
```

Begin a per-compile arena region; subsequent allocations bump-allocate
from it until the matching `arena_pop`. Nestable (depth-counted).

---

<a id="os.arena_pop" />
```gust
def foreign arena_pop() -> none
```

End the current arena region. When the outermost push is unwound, every
allocation made since it is freed at once. Anything that must survive must
first be copied out under a `arena_pause`/`arena_resume` window.

---

<a id="os.arena_pause" />
```gust
def foreign arena_pause() -> none
```

Temporarily route allocations back to the real heap (e.g. to deep-copy a
compile's result out of the arena before popping). Nestable.

---

<a id="os.arena_resume" />
```gust
def foreign arena_resume() -> none
```

Undo one `arena_pause`.

---

<a id="os.arena_active" />
```gust
def foreign arena_active() -> bool
```

True when an arena region is currently open on this thread (depth > 0).
Lets a callee skip its own push/promote/pop when it is already running
inside a caller's arena — the caller's pop will reclaim everything.

<a id="os.which" />
```gust
def which(name: string) -> string
```

Return the absolute path of `name` by searching `$PATH`, or the empty
string if no executable is found. If `name` contains a `/` it is checked
directly and returned as-is when executable. Symlinks are not resolved.

**Parameters**

- `name: string` — Executable name to locate, or a path containing a `/`.
