```gust
use toml
```

`encode` serializes a `dict[string, Any]` back into TOML text, the inverse
of `parse`. Nested `dict[string, Any]` values become `[table]` sections,
a list of tables becomes an `[[array-of-tables]]` block, `time.DateTime`
values render as RFC 3339 date-times, and remaining scalars/arrays render
inline as `key = value`.

A `none` value has no TOML representation, so any key (or array element)
holding `none` is omitted from the output.

**Examples**

```gust
use toml

def main() -> none
    cfg: dict[string, Any] = {}
    cfg["title"] = "app"
    print(toml.encode(cfg))   # title = "app"
end
```

## Functions

<a id="toml.encode" />
```gust
def encode(root: dict[string, Any]) -> string
```

Serialize a mapping to a TOML document.

Root scalars and arrays are emitted first as `key = value` lines, then
each nested table as a `[header]` section and each list-of-tables as a
sequence of `[[header]]` blocks. Table headers use the dotted key path,
quoting any segment that isn't a bare key. `time.DateTime` values render
with `DateTime.iso()`; `none` values are omitted.

The output round-trips through `parse`: `parse(encode(m))` reconstructs
an equivalent mapping.

**Parameters**

- `root: dict[string, Any]` — The mapping to serialize.
