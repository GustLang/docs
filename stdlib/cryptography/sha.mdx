```gust
use cryptography.sha
```

SHA-2 family hashes plus the legacy SHA-1, implemented in pure Gust (no C, no
external library) so they build everywhere the language does — including the
freestanding Pico target. The 32-bit-word hashes work entirely in 32-bit lanes
(masking every result with `& 0xFFFFFFFF`) to stay clear of the host integer's
sign bit; the 64-bit-word hashes carry each word as a [hi, lo] pair of 32-bit
lanes, since the host's signed 64-bit integer can't express unsigned 64-bit
arithmetic cleanly.

Provided: SHA-256 and SHA-224 (32-bit words), SHA-512 and SHA-384 (64-bit
words), plus the legacy SHA-1. Each hash is offered as a raw digest (`*_digest`
over a byte list), a `bytes` digest (`sha256`/`sha512`/`sha1`/…), and a
lowercase-hex string (`*_hex`). SHA-256 is the modern default for integrity,
commitments, and HMAC; SHA-1 is kept only for protocols that still mandate it
(e.g. the RFC 6455 WebSocket handshake) and must not be used for new security
work.

**Examples**

```gust
use cryptography.sha

def main() -> none
    digest := sha.sha256_hex("hello")
    print(digest)   # 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
end
```

<a id="cryptography.sha.sha1_digest" />
```gust
def sha1_digest(msg: list[integer]) -> list[integer]
```

Compute the SHA-1 digest of `msg` (byte values 0-255) and return it as a
list of 20 byte values.

**Parameters**

- `msg: list[integer]` — The message to hash, as a list of byte values.

<Warning>
SHA-1 is broken for collision resistance and must not be used for new
security work. It remains only for protocols that mandate it (e.g. the
RFC 6455 WebSocket handshake); prefer `sha256_digest` otherwise.
</Warning>
