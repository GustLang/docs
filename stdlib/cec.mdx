```gust
use cec
```

HDMI-CEC (Consumer Electronics Control) bus access — the low-speed control
channel on the HDMI wire that lets connected devices power each other on and
off, switch inputs, and pass remote-control keys.

`open` yields an `Adapter` over a Linux CEC character device (`/dev/cec<N>`).
An adapter needs a physical address (its position in the HDMI topology, e.g.
`0x1000` for "1.0.0.0") and one claimed logical address (a role on the bus,
e.g. `LogicalAddress.playback_1`) before it can send. On most systems the HDMI
driver reports the physical address for you; where it does not, set it with
`set_physical_address` before claiming.

`claim` hands back an adapter carrying the granted logical address, and only
that adapter can `transmit` — a message is always sent from an address the bus
actually granted. Incoming traffic arrives already decoded, as a `Msg`.

This package works on Linux only and in native builds only — it drives the
kernel CEC device directly. The CEC device is typically root-owned, so run
with the right privileges.

**Examples**

```gust
use cec

def main() -> none
    adapter := cec.open(0)
    if not adapter.ok()
        return
    end
    player := adapter.claim(cec.DeviceType.playback, "Gust")
    if player.claimed()
        # Ask the TV (logical address 0) to power on, then show our stream.
        player.transmit(cec.LogicalAddress.tv, cec.Opcode.image_view_on, [])
        player.transmit(cec.LogicalAddress.tv, cec.Opcode.active_source, [0x10, 0x00])
    end
    adapter.close()
end
```

<Note>
Only available on Linux.
</Note>

## `LogicalAddress`

<a id="LogicalAddress" />
```gust
enum LogicalAddress: integer
```

A role on the CEC bus. The 4-bit address identifies a device by function;
several `tuner`/`playback`/`recorder` slots exist so multiple devices of the
same kind can coexist. Pass one as a `transmit`/`ping` target, or compare it
against a decoded `Msg`.

**Variants**

- `tv = 0` — The television (the bus's root device).
- `recorder_1 = 1` — First recording device.
- `recorder_2 = 2` — Second recording device.
- `tuner_1 = 3` — First tuner.
- `playback_1 = 4` — First playback device.
- `audio_system = 5` — The audio/AV receiver.
- `playback_2 = 8` — Second playback device.
- `broadcast = 15` — Address 15 — every device on the bus when used as a destination, or an unregistered sender when used as an initiator.

## `DeviceType`

<a id="DeviceType" />
```gust
enum DeviceType: integer
```

The kind of device to present as when claiming a logical address with
`claim`. It selects which pool of logical addresses the kernel draws from.

**Variants**

- `tv = 0` — Television.
- `playback = 1` — Playback device (e.g. a media streamer).
- `recorder = 2` — Recording device.
- `tuner = 3` — Tuner.
- `audio = 4` — Audio system / AV receiver.

## `Opcode`

<a id="Opcode" />
```gust
enum Opcode: integer
```

A CEC message opcode — the command byte that follows the header. Pass one
to `transmit`; compare it against a decoded `Msg.opcode`. Opcodes outside
this set are still valid on the wire and may be sent as raw integers.

**Variants**

- `image_view_on = 4` — Wake the TV and select this source's input.
- `text_view_on = 13` — Wake the TV for a text/OSD display.
- `active_source = 130` — Announce this device as the active source.
- `standby = 54` — Put the addressed device(s) into standby.
- `user_control_pressed = 68` — Send a remote-control key press.
- `user_control_released = 69` — Release the last remote-control key.
- `give_osd_name = 70` — Request the device's on-screen name.
- `set_osd_name = 71` — Report an on-screen name.
- `give_physical_address = 131` — Request the device's physical address.
- `report_physical_address = 132` — Report a physical address.
- `request_active_source = 133` — Ask which device is the active source.
- `set_stream_path = 134` — Make the device at a physical address the active source.
- `give_device_vendor_id = 140` — Request the device's vendor ID.
- `give_device_power_status = 143` — Request the device's power state.
- `report_power_status = 144` — Report a power state.
- `get_cec_version = 159` — Request the device's CEC version.
- `cec_version = 158` — Report a CEC version.

## `Adapter`

<a id="Adapter" />
An open CEC adapter, and the logical address it speaks as.

`open` yields an unclaimed adapter: it can receive and probe, but it has no
address to send from yet. `claim` returns a second `Adapter` on the same
device that carries the granted address, and that is the one `transmit`
works from — so a message can never be sent from an address the bus has not
granted.

```gust
def Adapter

    handle: integer
    logical_address: integer

end
```

**Fields**

- `handle: integer` — The open CEC character device, or -1 if it could not be opened.
- `logical_address: integer` — The claimed bus address, or `0xFF` when unclaimed.

**Methods**

<a id="Adapter.ok" />
```gust
def Adapter.ok() -> bool
```

Whether the adapter device is open.

---

<a id="Adapter.claimed" />
```gust
def Adapter.claimed() -> bool
```

Whether a logical address has been granted, which `transmit` needs.

---

<a id="Adapter.claim" />
```gust
def Adapter.claim(device_type: DeviceType, osd_name: string) -> Adapter
```

Claim a logical address on the bus for a device of `device_type`,
advertising `osd_name` as the on-screen name (up to 14 characters). The
kernel picks a free address for the role.

Returns an adapter carrying the granted address; when no address could be
claimed — for example when the adapter has no physical address yet — the
returned adapter reports `claimed` false.

**Parameters**

- `device_type` — The role to present as.
- `osd_name` — On-screen device name reported to other devices.

---

<a id="Adapter.set_physical_address" />
```gust
def Adapter.set_physical_address(address: integer) -> bool
```

Set the adapter's 16-bit physical address — its position in the HDMI
topology, e.g. `0x1000` for "1.0.0.0". Only needed when the HDMI driver does
not report it automatically, and it must be set before `claim`.

**Parameters**

- `address` — 16-bit physical address.

**Returns** `bool`

True when the address was accepted.

---

<a id="Adapter.physical_address" />
```gust
def Adapter.physical_address() -> integer
```

The adapter's current 16-bit physical address, or -1 on error. `0xFFFF`
means no address is configured.

---

<a id="Adapter.transmit" />
```gust
def Adapter.transmit(
    destination: integer,
    opcode: integer,
    operands: list[integer],
) -> bool
```

Send a message to `destination` with `opcode` and `operands` (each
truncated to a byte), from this adapter's claimed logical address.

**Parameters**

- `destination` — Target logical address, or `LogicalAddress.broadcast`.
- `opcode` — Message opcode (an `Opcode` variant or a raw byte).
- `operands` — Operand bytes following the opcode.

**Returns** `bool`

True when the message was acknowledged; false on NACK, on error, or
when no logical address has been claimed.

---

<a id="Adapter.ping" />
```gust
def Adapter.ping(destination: integer) -> bool
```

Send a header-only polling message to probe whether `destination` is
present on the bus.

**Parameters**

- `destination` — Logical address to probe.

**Returns** `bool`

True if the address acknowledged.

---

<a id="Adapter.receive" />
```gust
def Adapter.receive(timeout_ms: integer) -> Msg
```

Wait up to `timeout_ms` milliseconds for an incoming message.

**Parameters**

- `timeout_ms` — Maximum time to wait, in milliseconds.

**Returns** `Msg`

The decoded message, or an empty `Msg` on timeout or error — test it
with `Msg.is_empty`.

---

<a id="Adapter.close" />

## `Msg`

**Fields**

- `opcode: integer` — Message opcode, or -1 for a header-only poll.

## Functions

<a id="cec.open" />
```gust
def open(index: integer) -> Adapter
```

Open CEC adapter `index` (`/dev/cec<index>`) and put it into
initiator + follower mode so it can both send and receive.

An adapter that cannot be opened is returned closed rather than raising —
check `ok`. Claim a logical address with `claim` before transmitting.

**Parameters**

- `index: integer` — CEC adapter number.
