```gust
use time
```

Core time access: read the current time and timestamp, and pause execution
for a given number of milliseconds or microseconds.

`now()` returns a `DateTime` (see `datetime.g`). For lightweight timing, take
the Unix millisecond timestamp from it with `timestamp()` or an `integer` cast.

**Examples**

```gust
use time

def main() -> none
    dt := time.now()
    print(dt)                       # e.g. 2026-04-14 18:30:45 UTC
    print(dt.timestamp())           # Unix milliseconds
    print(time.now() as integer)    # the same, as a cast
    print(dt.format("%Y-%m-%d"))    # 2026-04-14
end
```

## `DateTime`

<a id="DateTime" />
A point in time, broken down into calendar fields plus a Unix
millisecond timestamp and a timezone label.

Construct one with `time.now()`, `time.from_timestamp(ms)`,
`time.from_fields(...)`, or `time.parse(...)`, and move it between
timezones with `to`. The calendar fields describe the instant as seen in
`timezone`; `ms` is the same instant in every timezone.

```gust
def DateTime

    year: integer
    month: integer
    day: integer
    hour: integer
    minute: integer
    second: integer
    ms: integer
    timezone: string

end
```

**Fields**

- `year: integer` — Calendar year.
- `month: integer` — Calendar month (1-12).
- `day: integer` — Day of the month.
- `hour: integer` — Hour of the day (0-23).
- `minute: integer` — Minute of the hour (0-59).
- `second: integer` — Second of the minute (0-59).
- `ms: integer` — Unix timestamp in milliseconds.
- `timezone: string` — Timezone label (e.g. 'UTC').

**Methods**

<a id="DateTime.to" />
```gust
def DateTime.to(tz: string) -> DateTime
```

<Note>
Only available on Linux and macOS.
</Note>

The same instant seen from a different timezone. The calendar fields
shift; `ms` does not.

Reads the system timezone database, so it exists only on a target that has
one; a board with no database has no `to`, and a call to it is a compile
error rather than a runtime failure.

**Parameters**

- `tz` — Target timezone label, e.g. 'Asia/Tokyo'. The `time` package defines constants for common zones.

**Raises**

- `ValueError` — `tz` names no zone in the database.

<a id="DateTime.format" />
```gust
def DateTime.format(fmt: string) -> string
```

Render this DateTime with strftime-style `%`-directives.

Supported directives:

```gust
%Y full year      %y 2-digit year    %m month (01-12)
%d day (01-31)    %H hour (00-23)    %I hour (01-12)
%M minute         %S second          %p AM/PM
%j day-of-year    %B month name      %b month abbr
%A weekday name   %a weekday abbr    %Z timezone label
%z ±HHMM offset   %% a literal %
```

Any other `%X` sequence is emitted unchanged.

**Parameters**

- `fmt` — The format string.

## `Duration`

<a id="Duration" />
A span of time.

The span is stored once, in milliseconds; every other unit is a whole-unit
view of it, truncated toward zero. A span from a `since` that runs backwards
is negative.

```gust

end
```

**Fields**

- `ms: integer` — The span in milliseconds.

**Methods**

## Functions

<a id="time.sleep" />
```gust
def foreign sleep(ms: integer) -> none
```

Pauses execution for the given number of milliseconds.

A signal delivered to a handler partway through does not cut the wait
short: whatever is left of it is waited out, so the figure asked for is
the figure spent.

**Parameters**

- `ms: integer` — Number of milliseconds to sleep.

---

<a id="time.sleep_us" />
```gust
def foreign sleep_us(us: integer) -> none
```

Pauses execution for the given number of microseconds.

Sub-millisecond waits are what a bit-banged bus is made of. A device
datasheet gives its setup, hold and settling times in microseconds, and a
driver that rounds each of them up to a whole millisecond runs orders of
magnitude slower than the part it is talking to allows.

The floor is the platform's rather than this call's. A hosted system
schedules other work while it waits, so a short sleep returns once the
scheduler comes back round and the figure is a minimum rather than a
duration. Bare metal has no scheduler in the way and the wait is the
hardware timer's, good to about a microsecond.

As with `sleep`, a signal arriving partway through does not shorten the
wait.

**Parameters**

- `us: integer` — Number of microseconds to sleep.

<a id="time.parse" />
```gust
def parse(s: string, fmt: string) -> DateTime
```

Parse `s` according to strftime-style `fmt`, returning a UTC `DateTime`.

Recognizes the same directives as `DateTime.format`. Unspecified fields
default to 1970-01-01 00:00:00. Whitespace in `fmt` matches any run of
whitespace in the input; a literal character in `fmt` must match the input
exactly.

**Parameters**

- `s: string` — The text to parse.
- `fmt: string` — The strftime-style format describing `s`.

**Raises**

- `ValueError` — when the input does not match `fmt` (a literal mismatch or an expected month name that is absent).

---

<a id="time.parse_iso" />
```gust
def parse_iso(s: string) -> DateTime
```

Parse an ISO 8601 / RFC 3339 timestamp into a UTC `DateTime`.

Accepts date-only (`2026-06-23`), date-time with a `T` or space separator
(`2026-06-23T14:30:45`), optional fractional seconds (`.123`), and an
optional trailing `Z` or `±HH:MM` offset. The result is normalized to UTC.

**Parameters**

- `s: string` — The ISO 8601 string to parse.

**Raises**

- `ValueError` — when `s` is shorter than a bare `YYYY-MM-DD` date.
