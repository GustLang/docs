```gust
use time
```

DateTime values: a calendar date and time of day paired with a Unix
millisecond timestamp and a timezone label. Provides construction from a
timestamp in a given timezone, conversion between timezones, string and
dict rendering, and elapsed/difference durations.

**Examples**

```gust
use time

def main() -> none
    dt := time.now()
    tokyo := dt.to("Asia/Tokyo")
    print(tokyo.timezone)           # Asia/Tokyo
    print(dt.since(tokyo))          # 0ms — same instant, different label
end
```

## `DateTime`

<a id="DateTime" />
A point in time, broken down into calendar fields plus a Unix
millisecond timestamp and a timezone label. Construct one with
`time.now()` or `time.to_timezone(ms, tz)`.

```gust
def DateTime

    year: integer
    month: integer
    day: integer
    hour: integer
    minute: integer
    second: integer
    ms: integer
    timezone: string

end
```

**Fields**

- `year: integer` — Calendar year.
- `month: integer` — Calendar month (1-12).
- `day: integer` — Day of the month.
- `hour: integer` — Hour of the day (0-23).
- `minute: integer` — Minute of the hour (0-59).
- `second: integer` — Second of the minute (0-59).
- `ms: integer` — Unix timestamp in milliseconds.
- `timezone: string` — Timezone label (e.g. 'UTC').

**Methods**

<a id="DateTime.iso" />
```gust
def DateTime.format(fmt: string) -> string
```

Render this DateTime with strftime-style `%`-directives.

Supported directives:

```gust
%Y full year      %y 2-digit year    %m month (01-12)
%d day (01-31)    %H hour (00-23)    %I hour (01-12)
%M minute         %S second          %p AM/PM
%j day-of-year    %B month name      %b month abbr
%A weekday name   %a weekday abbr    %Z timezone label
%z ±HHMM offset   %% a literal %
```

Any other `%X` sequence is emitted unchanged.

**Parameters**

- `fmt` — The format string.

<a id="time.parse" />
```gust
def parse(s: string, fmt: string) -> DateTime
```

Parse `s` according to strftime-style `fmt`, returning a UTC `DateTime`.

Recognizes the same directives as `DateTime.format`. Unspecified fields
default to 1970-01-01 00:00:00. Whitespace in `fmt` matches any run of
whitespace in the input; a literal character in `fmt` must match the input
exactly.

**Parameters**

- `s: string` — The text to parse.
- `fmt: string` — The strftime-style format describing `s`.

**Raises**

- `ValueError` — when the input does not match `fmt` (a literal mismatch or an expected month name that is absent).

---

<a id="time.parse_iso" />
```gust
def parse_iso(s: string) -> DateTime
```

Parse an ISO 8601 / RFC 3339 timestamp into a UTC `DateTime`.

Accepts date-only (`2026-06-23`), date-time with a `T` or space separator
(`2026-06-23T14:30:45`), optional fractional seconds (`.123`), and an
optional trailing `Z` or `±HH:MM` offset. The result is normalized to UTC.

**Parameters**

- `s: string` — The ISO 8601 string to parse.

**Raises**

- `ValueError` — when `s` is shorter than a bare `YYYY-MM-DD` date.
