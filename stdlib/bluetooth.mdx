```gust
use bluetooth
```

A cross-platform Bluetooth Low Energy API covering both roles:

- Peripheral: advertise and expose a GATT server (services / characteristics
  that a central can read, write, and subscribe to).
- Central: scan for peripherals, connect, and read / write their
  characteristics by UUID.

Backends are selected at the C-compile step. Both roles work on the Raspberry
Pi Pico 2 W (CYW43 + BTstack) and on the Linux host: the central role uses
BlueZ kernel sockets (HCI scan + L2CAP ATT), and the peripheral role registers
a GATT server + LE advertisement with BlueZ over D-Bus (sd-bus). macOS and
Windows are a compile-time error until their backends exist, rather than a
misleading no-op. On Linux, both roles need privileges (HCI scanning needs
CAP_NET_RAW + CAP_NET_ADMIN; registering a GATT app/advert with BlueZ is
privileged too) — run as root. UUIDs use the `UUID` type: `UUID(value: 0x181A)`
(16-bit) or `UUID(value: "0000180d-0000-1000-8000-00805f9b34fb")` (128-bit).
Byte payloads are `list[integer]`.

Scan for a peripheral, connect to the first result, and read a characteristic:

**Examples**

```gust
use bluetooth

def main() -> none
    HEART_RATE := bluetooth.UUID(value: "00002a37-0000-1000-8000-00805f9b34fb")
    if bluetooth.scan(2000) > 0 and bluetooth.connect(bluetooth.scan_addr(0), 5000)
        print(bluetooth.read(HEART_RATE, 2000))
        bluetooth.disconnect()
    end
end
```

## `UUID`

<a id="UUID" />
A Bluetooth UUID — a 16-bit code or a 128-bit string. Construct it with
the `value` field.

`print(u)` / f-strings render the canonical text, and `==` compares two
UUIDs. Pass it to any API that takes a UUID (add_service / read / …).

```gust
def UUID

    value: integer | string

end
```

**Fields**

- `value: integer | string` — The UUID as a 16-bit integer code or a 128-bit dashed string.

**Examples**

```gust
ENV  := bluetooth.UUID(value: 0x181A)
UART := bluetooth.UUID(value: "6e400001-b5a3-f393-e0a9-e50e24dcca9e")
```
