```gust
use json
```

The RFC 8259 parser and serializer for the JSON package. `parse` (and its
encode-inverse alias `decode`) turn a JSON string into native Gust values — an
object becomes a `dict[string, Any]`, an array a `list[Any]`, a string/number/
boolean the matching primitive, and `null` becomes `none`. `encode` serializes an
arbitrary Gust value back to compact JSON through its `__dict` conversion.

**Examples**

```gust
use json

def main() -> none
    nums := json.parse("[1, 2, 3]")
    print(json.encode(nums))   # [1,2,3]
end
```

## `JsonParser`

<a id="JsonParser" />
Byte cursor over the JSON source.

```gust
def JsonParser

    src: string
    pos: integer
    depth: integer

end
```

**Fields**

- `src: string` — The JSON text being parsed.
- `pos: integer` — Current byte offset into `src`.
- `depth: integer` — Current container nesting, capped at JSON_MAX_DEPTH.

**Methods**

<a id="JsonParser.fail" />
```gust
def JsonParser.fail() -> none
```

Abort the parse at the current cursor position.

**Raises**

- `ValueError` — Always, naming the byte offset of the failure.

## Functions

<a id="json.encode" />
```gust
def foreign encode(value: Any) -> string
```

Serialize any value to a compact JSON string. Primitives, lists, tuples,
and dicts map to the corresponding JSON forms; a struct serializes as a JSON
object through its `__dict` conversion, which selects and names the fields
(define `__dict` on the struct to customize the shape). Dict and tuple keys
render as strings. Object member order follows the source value.

**Parameters**

- `value: Any` — The value to serialize.

---

<a id="json.parse" />
```gust
def parse(s: string) -> Any
```

Parse `s` as JSON and return the root value as native Gust data: an
object becomes a `dict[string, Any]`, an array a `list[Any]`, a scalar its
matching primitive, and `null` becomes `none`.

**Parameters**

- `s: string` — The JSON text to parse.

**Raises**

- `ValueError` — On malformed input, naming the byte offset of the mismatch (including trailing content after an otherwise-complete value).

---

<a id="json.decode" />
```gust
def decode(s: string) -> Any
```

Parse `s` as JSON into native Gust values. The encode-inverse name for
`parse`; both are identical.

**Parameters**

- `s: string` — The JSON text to parse.

**Raises**

- `ValueError` — On malformed input, naming the byte offset of the mismatch.

<a id="json.apply_patch" />
```gust
def apply_patch(doc: Any, patch: Any) -> Any
```

Apply every operation in `patch` to `doc`, in order, and return the
resulting document.

The return value is the new root: every operation but one mutates `doc` in
place and hands the same root back, while an operation whose path is `""`
replaces the root outright and hands back what replaced it. Assign the
result rather than relying on the mutation.

**Parameters**

- `doc: Any` — The document to patch, as parsed values.
- `patch: Any` — A JSON Patch document — a list of operation objects.

**Raises**

- `ValueError` — If `patch` is not a list of operation objects, an operation names an unknown `op` or lacks the members that `op` requires, a path does not resolve, or a `test` operation fails.

---

<a id="json.apply_op" />
```gust
def apply_op(doc: Any, op: dict[string, Any]) -> Any
```

Apply one patch operation to `doc` and return the resulting document.

**Parameters**

- `doc: Any` — The document to patch.
- `op: dict[string, Any]` — One operation object, with `op` and `path` members plus whatever that operation requires (`value` for add/replace/test, `from` for move/copy).

**Raises**

- `ValueError` — If the operation is malformed, its path does not resolve, or it is a `test` that fails.

---

<a id="json.pointer" />
```gust
def pointer(doc: Any, path: string) -> Any
```

The value `path` points at, as an RFC 6901 JSON Pointer.

**Parameters**

- `doc: Any` — The document to read from.
- `path: string` — A JSON Pointer, e.g. `"/liveData/plays/allPlays/0"`. `""` is the document itself.

**Raises**

- `ValueError` — If `path` is not a well-formed pointer, or names a member or element that isn't there.
