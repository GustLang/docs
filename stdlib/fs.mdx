Filesystem and path operations: querying and changing the working directory,
building and splitting paths, file and directory reads/writes/creation/removal,
recursive walking and copying, globbing, temp files and directories, and a
`Path` wrapper that exposes these as method-style helpers (`.read()`,
`.write()`, `.parent()`, `.ext()`, and more).

**Examples**

```gust
use fs

def main() -> none
    fs.write_file("notes.txt", "hello\n")
    print(fs.read_file("notes.txt"))   # hello

    p := fs.Path(path: "/src/main.g")
    print(p.stem())                    # main
    print(p.ext())                     # .g
end
```

## `Path`

<a id="Path" />
A filesystem path. Wrap a string with `Path(path: "...")` to use the
method-style helpers (`.read()`, `.write()`, `.parent()`, `.ext()`, etc.).

```gust

end
```

**Fields**

- `path: string` — The path string this wrapper holds.

**Methods**

## `Event`

<a id="Event" />
A single filesystem change reported by a `Watcher`.

```gust
def Event

    wd: integer
    mask: integer
    cookie: integer
    name: string
    path: string

end
```

**Fields**

- `wd: integer` — The watch descriptor the change occurred under, matching the value `Watcher.add` returned for that path.
- `mask: integer` — Bitmask of `IN_*` flags describing what happened. Inspect it with the `is_*` helpers or `has`.
- `cookie: integer` — Correlation id linking a `IN_MOVED_FROM` event to its matching `IN_MOVED_TO` (a rename). Zero for events that aren't part of a move.
- `name: string` — The affected entry's name relative to the watched directory, or "" when the event targets the watched path itself.
- `path: string` — The affected entry's full path — the watched directory joined with `name` — or the watched path itself when `name` is empty.

**Methods**

<a id="Event.has" />
```gust
def Event.has(flag: integer) -> bool
```

True if `flag` is set in this event's mask.

**Parameters**

- `flag` — An `IN_*` constant to test for.

---

<a id="Event.is_create" />
```gust
def Event.is_create() -> bool
```

True if a file or directory was created in the watched directory.

---

<a id="Event.is_delete" />
```gust
def Event.is_delete() -> bool
```

True if a file or directory was deleted from the watched directory.

---

<a id="Event.is_modify" />
```gust
def Event.is_modify() -> bool
```

True if the contents of a watched file were modified.

---

<a id="Event.is_moved_from" />
```gust
def Event.is_moved_from() -> bool
```

True if the entry was moved out of the watched directory (the source
half of a rename); pair it with the matching `is_moved_to` event by
`cookie`.

---

<a id="Event.is_moved_to" />
```gust
def Event.is_moved_to() -> bool
```

True if the entry was moved into the watched directory (the destination
half of a rename); pair it with the matching `is_moved_from` event by
`cookie`.

---

<a id="Event.is_dir" />
```gust
def Event.is_dir() -> bool
```

True if the event's subject is a directory rather than a file.

## `Watcher`

<a id="Watcher" />
An open inotify instance tracking one or more paths. Create with
`watch()`, register paths with `add` (or `add_recursive`), then drain events
with `read` or `poll`. Close it with `close` when done.

```gust
def Watcher

    _fd: integer
    _open: bool
    _paths: dict[integer, string]

end
```

**Fields**

- `_fd: integer` — The underlying inotify file descriptor.
- `_open: bool` — False once `close` has been called.
- `_paths: dict[integer, string]` — Maps each active watch descriptor to the path it watches, used to resolve every event to a full `path`.

**Methods**

<a id="Watcher.add" />
```gust
def Watcher.add(path: string, mask: integer) -> integer
```

Watch `path` for the changes selected by `mask` and return its watch
descriptor. Re-adding an already-watched path updates its mask and returns
the same descriptor.

**Parameters**

- `path` — The file or directory to watch.
- `mask` — Bitwise-or of the `IN_*` flags to report.

**Raises**

- `IOError` — when the path can't be watched.

---

<a id="Watcher.add_recursive" />
```gust
def Watcher.add_recursive(path: string, mask: integer) -> integer
```

Watch `path` and every directory beneath it with the same `mask`,
returning the watch descriptor of `path` itself.

This covers the tree as it exists now. inotify watches are not inherited by
directories created later, so a live observer should also watch for
`IN_CREATE` with `IN_ISDIR` set and `add` each new subdirectory as it
appears.

**Parameters**

- `path` — The root directory to watch recursively.
- `mask` — Bitwise-or of the `IN_*` flags to report.

**Raises**

- `IOError` — when a directory in the tree can't be watched.

---

<a id="Watcher.remove" />
```gust
def Watcher.remove(wd: integer) -> none
```

Stop watching the path registered under watch descriptor `wd`.

**Parameters**

- `wd` — A descriptor returned by `add`.

**Raises**

- `IOError` — when `wd` is not a valid descriptor for this watcher.

---

<a id="Watcher.read" />
```gust
def Watcher.read() -> list[Event]
```

Block until at least one change occurs, then return every event drained
in that batch. Never returns an empty list.

**Raises**

- `IOError` — when the underlying read fails.

---

<a id="Watcher.poll" />
```gust
def Watcher.poll(timeout_ms: integer) -> list[Event]
```

Wait up to `timeout_ms` milliseconds for changes and return the events
drained, or an empty list if the timeout elapses first. A negative timeout
blocks indefinitely (like `read`); zero returns immediately with whatever is
already queued.

**Parameters**

- `timeout_ms` — Maximum time to wait, in milliseconds.

---

<a id="Watcher.close" />
```gust
def Watcher.close() -> none
```

Close the watcher and release its inotify instance and all watches.
Idempotent — closing an already-closed watcher is a no-op.

---

<a id="Watcher.is_open" />
```gust
def Watcher.is_open() -> bool
```

True while the watcher has not been closed.

---

<a id="Watcher.fd" />
```gust
def Watcher.fd() -> integer
```

The raw inotify file descriptor, for callers polling it alongside other
descriptors in their own event loop.

<a id="fs.remove_tree" />
```gust
def remove_tree(path: string) -> none
```

Recursively delete `path` and everything under it. Files are unlinked;
directories are cleared bottom-up and then removed. Symbolic links are
unlinked, not followed. A missing path is a silent no-op, which suits
cache cleanup.

**Parameters**

**Raises**

- `IOError` — when an entry under `path` can't be removed.

<Warning>

</Warning>
