title: mmap
description: "Memory-mapped regions through the POSIX `mmap` call"
---

```gust
use mmap
```

Memory-mapped regions through the POSIX `mmap` call. A successful `map`
returns the base address of the mapping as an `integer`, ready to hand to the
`unsafe` load/store primitives; `unmap` releases it. Protection and flag
values are the `PROT_*` / `MAP_*` foreign constants, whose values the C library
of the target being built defines.

Available on native builds for Linux, macOS and the BSDs. Windows, the
microcontroller targets and the browser have no `mmap` package: an import there
resolves to nothing and every reference is a compile error.

**Examples**

```gust
use mmap
use unsafe

def main() -> none
    # A 4 KiB anonymous, writable, private scratch region.
    size := 4096
    addr := mmap.map(-1, size, mmap.PROT_READ | mmap.PROT_WRITE,
                     mmap.MAP_PRIVATE | mmap.MAP_ANONYMOUS, 0)
    if addr < 0
        return
    end
    unsafe.store32(addr, 0, 0xCAFE)
    mmap.unmap(addr, size)
end
```

<Note>
Only available on native builds, and not on Windows.
</Note>

## Functions

<a id="mmap.map" />
```gust
def foreign map(
    fd: integer,
    length: integer,
    prot: integer,
    flags: integer,
    offset: integer,
) -> integer
```

Map `length` bytes of the object referred to by `fd` into memory and
return the base address, or -1 on error. For an anonymous mapping (backed
by zero-filled pages rather than a file), set `MAP_ANONYMOUS` in `flags`;
`fd` is then ignored and conventionally passed as -1.

**Parameters**

- `fd: integer` — File descriptor to map, or -1 for an anonymous mapping.
- `length: integer` — Number of bytes to map.
- `prot: integer` — Bitwise OR of the `PROT_*` constants (page protection).
- `flags: integer` — Bitwise OR of the `MAP_*` constants (visibility and backing).
- `offset: integer` — Byte offset into the object; must be a multiple of the page size.

---

<a id="mmap.unmap" />
```gust
def foreign unmap(addr: integer, length: integer) -> integer
```

Release a mapping created by `map`. Returns 0 on success, -1 on error.

**Parameters**

- `addr: integer` — Base address returned by `map`.
- `length: integer` — Byte length the mapping was created with.

---

<a id="mmap.sync" />
```gust
def foreign sync(addr: integer, length: integer) -> integer
```

Flush changes made to a shared, file-backed mapping to the underlying
object. Returns 0 on success, -1 on error.

**Parameters**

- `addr: integer` — Base address returned by `map`.
- `length: integer` — Number of bytes to flush.
