---
title: Standard library
description: "Gust's batteries-included standard library — importable packages plus the built-in type methods"
---

Each package is a `.g` declaration file paired with a C implementation that links into your binary automatically. Import with `use <pkg>`; members are accessed as `pkg.name`. The [Builtins](/builtins/prelude) section covers the prelude and the methods on the built-in types.

## Importing

```gust
use math
use time

def main() -> none
    print(math.sqrt(2.0))
    print((time.now() as integer))
end
```

## Core

| Package | Description |
|---------|-------------|
| [`math`](/stdlib/math) | Numeric limits, constants, and mathematical functions: the integer and float range bounds, the constants π, τ, e, infinity, and NaN, absolute value, rounding and truncation, sign and comparison helpers, division remainders, powers and roots, exponentials and logarithms, trigonometric and hyperbolic functions, angle conversion, float classification, and integer helpers such as `gcd`, `lcm`, and `factorial` |
| [`convert`](/stdlib/convert) | Integer base conversions: format an integer as a hex, octal, or binary string (with the conventional `0x` / `0o` / `0b` prefix) and parse such strings back to integers, honoring an optional sign and prefix |
| [`time`](/stdlib/time) | Core time access: read the current time and timestamp, and pause execution for a given number of milliseconds or microseconds |
| [`uuid`](/stdlib/uuid) | Universally Unique Identifiers (RFC 4122 / RFC 9562) |

## System

| Package | Description |
|---------|-------------|
| [`os`](/stdlib/os) | System-level utilities: the operating-system and hardware identity (platform, OS version, architecture, hostname, byte order), process identity through `process()` (pid, ppid, uid, username, executable path, command-line arguments), standard-stream I/O, executable lookup on `$PATH`, and a per-compile arena allocator for batch drivers |
| [`fs`](/stdlib/fs) | Filesystem and path operations: querying and changing the working directory, building and splitting paths, file and directory reads/writes/creation/removal, recursive walking and copying, globbing, temp files and directories, and a `Path` wrapper that exposes these as method-style helpers (`.read()`, `.write()`, `.parent()`, `.ext()`, and more) |
| [`exitcode`](/stdlib/exitcode) | Standard process exit codes, named as constants |
| [`signal`](/stdlib/signal) | Unix signal handling |
| [`profile`](/stdlib/profile) | A deterministic section profiler |
| [`mmap`](/stdlib/mmap) | Memory-mapped regions through the POSIX `mmap` call |
| [`ioctl`](/stdlib/ioctl) | Device control through the POSIX `ioctl` call |
| [`dl`](/stdlib/dl) | Load shared libraries at runtime and call into them |

## Cryptography

| Package | Description |
|---------|-------------|
| [`cryptography.sha`](/stdlib/cryptography/sha) | SHA-2 family hashes plus the legacy SHA-1, implemented in pure Gust (no C, no external library) so they build everywhere the language does — including the freestanding Pico target |
| [`cryptography.hmac`](/stdlib/cryptography/hmac) | HMAC (keyed-hash message authentication code, RFC 2104), implemented in pure Gust on top of `cryptography.sha` |
| [`cryptography.kdf`](/stdlib/cryptography/kdf) | Key derivation functions, implemented in pure Gust over `cryptography.hmac` (HMAC-SHA-256) |
| [`cryptography.random`](/stdlib/cryptography/random) | Random number generation, in two flavors that must not be confused: |
| [`cryptography.aes`](/stdlib/cryptography/aes) | Authenticated AES encryption (AES-GCM), backed by the system OpenSSL (`libcrypto`) |
| [`cryptography.bcrypt`](/stdlib/cryptography/bcrypt) | bcrypt password hashing, backed by the system libxcrypt (`crypt_rn` / `crypt_gensalt_rn` with the `$2b$` prefix) |
| [`cryptography.ed25519`](/stdlib/cryptography/ed25519) | Ed25519 digital signatures |
| [`cryptography.x25519`](/stdlib/cryptography/x25519) | X25519 Elliptic-Curve Diffie-Hellman key exchange, backed by the system OpenSSL (`libcrypto`) |
| [`cryptography.ssl`](/stdlib/cryptography/ssl) | TLS/SSL for byte-stream sockets, layered over the `socket` package |
